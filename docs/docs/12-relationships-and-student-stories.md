# 学生关系、共同生活与人物故事

[返回 README](../README.md) · [学生生命周期](03-students-and-legacy.md) · [事件系统](06-events-and-world.md) · [课程与教研](10-curriculum-and-research.md)

本篇为阶段 3 起逐步接入的人物内容草案，复杂关系链与学长回访主要在阶段 6～7 扩展。角色故事依赖真实日程、比赛和承诺，不预先指定谁必须成为冠军、退役者或反派。

## 1. 学生不是一张天赋排行榜

同样的分数可以来自不同经历：有人认真检查却知识不足，有人思维快但写不完，有人参加比赛只是希望和朋友一起做题。玩家看到的目标、说话方式和日常行为，应与这些经历相互印证。

故事只提供选择与可追溯后果，不给学生永久“好学生 / 坏学生”标签。一次拒绝训练、一次家长反对或一次成绩低谷，都不能直接确定人格与最终去向。

现有心情、热爱、压力、倦怠、关系值和事件标记足以驱动大部分叙事。以下“信任、归属、比较焦虑”等描述优先从这些事实派生，不全部新增独立 0～100 资源条。

## 2. 性格的行为维度

| 维度 | 更偏一端的行为 | 玩家应观察的信号 | 不应作出的推断 |
|---|---|---|---|
| 表达习惯 | 主动提问或先独自思考 | 谈话形式、群体发言 | 安静不代表没热爱 |
| 竞争倾向 | 喜欢榜单或更看重个人进步 | 赛后关注对象 | 不爱排名不等于没有目标 |
| 风险偏好 | 先保部分分或愿意冲难题 | 选题与止损 | 冒险不必然聪明或莽撞 |
| 反馈偏好 | 需要明确建议或更需要自主空间 | 对不同谈话的回应 | 不能靠固定“正确话术”通吃 |
| 秩序偏好 | 依赖稳定模板或喜欢探索 | 改课后的适应 | 喜欢变化不等于不可靠 |
| 社交节奏 | 小范围深交或多人活动 | 结伴与休息方式 | 独处不自动产生负面状态 |

性格影响行为倾向和建议，不代替能力。对同一学生连续多次只显示同一种气泡会显得刻板，因此日常表现还要读取当天活动、关系和近期记忆。

## 3. 目标、目标变化与多重身份

每人默认一个主要目标、一个次要愿望。主要目标可以是获得竞赛机会、探索算法、与朋友共同成长或验证自己；次要愿望可以是完成一次命题、带一位学弟学妹、保住文化课节奏。

目标保存提出时间、本人措辞、相关证据、复查日期和是否仍愿意坚持。学生可以改变主意；修改目标不删除过去努力，也不自动清空热爱。目标过时后，面板显示“需要重谈”，不能永远拿初一的保送愿望要求高三学生。

家庭、班级、校队与个人兴趣是并存身份。参加班级活动挤占一个训练时段时，玩家可以调整计划；不把每次非 OI 选择都解释为背叛校队。

## 4. 记忆与承诺的最小模型

每条重要记忆保留事件 ID、相关对象、日期、事实摘要、当时回应和后续是否兑现。常规聊天只进入短期日志，主要比赛、公开表扬、失约、共同项目和离队协商进入长期档案。

记忆影响未来事件的可选分支。例如“上次答应先休息却仍连排模拟赛”会让下一次安慰缺乏说服力；确实完成休整与复谈后可逐步修复。不能通过一张廉价礼物卡直接删除失约记录。

同类小事件按一周聚合，防止七次普通提醒叠成七份永久惩罚。多年后保留关键经历和结论，删除无用细节；历史事实不因关系回升而被改写。

## 5. 关系图的边与变化

友谊、竞争、师徒和同项目伙伴是可以同时存在的关系类型，边带近期证据与强度。两人既能互相竞争，也能在赛后一起对拍。

普通共同活动每周对同一关系最多产生一次主要变化，避免同桌反复交换位置刷关系。关系增减统一限制在既有 -100～100 范围；数值变化需要写明“共同完成任务”“未兑现约定”等来源。

关系不是双向完全对称的：甲把乙当作榜样，不代表乙已经和甲建立师徒关系。正式结对需双方确认，公开展示须得到角色事件中的许可；已退役者仍能是朋友，但不能继续占用在队学生位。

## 6. 机房日常与低打断叙事

日常可包括排队接水、讨论反例、抢最后一块饼干、一起清理白板、午后打瞌睡、考前检查文件名。大多以场景动作和短日志呈现，不需要弹出三选一。

若日常只提供气氛，不额外结算 XP、体力或关系。若玩家选择举办团建、互助讲题或机房整理，则成为实际活动，占用日程并应用对应已有结算。不能“路过聊一句”同时获得完整休息和讲评收益。

同一风味消息有冷却和条件，学生已不在场、正在正式赛或睡眠时不能说不合时宜的话。气泡只展示本人可能知道的信息，不能让学生在无反馈赛中喊出正式测试得分。

## 7. 比较、冲突与公开反馈

榜单只描述一次比赛结果。教练可以公开庆祝团体进步、表扬具体过程或私下反馈；公开点名“你一定比他强”可能增加当事人的压力与被比较者的不满。

冲突先区分资源与情绪：座位噪音、设备不足、项目署名、名额规则和误会需要不同解决办法。换座位能解决噪音，不自动修复被抢署名的经历；一次谈话能澄清规则，不凭空增加一个晋级席位。

对欺凌、持续骚扰或作弊指控使用事实调查和明确行为边界，不能把受影响学生简单记成“玻璃心”。暂停相关活动与保护正常学习可立即执行，永久处分需要后续流程。

## 8. 师徒、共同项目与小团体

正式师徒默认一对一，指导者需掌握主题且双方出勤。一次传帮带替代指导者的个人练习，并按课程文档产生相应收益；同一时段不允许甲教乙、乙教甲来回叠加。

小团体可形成“反例三人组”“晨间题解桌”等生活标签，主要用于推荐合作与故事。没有群体自动全队成长光环。项目收益按实际参加者和工作分配结算，旁观者不会因站在房间里自动获得满额知识。

玩家可以邀请成员重新分工，但不直接删除友谊。若团体排斥新人，可提供共同小任务、轮换讨论搭档和个人沟通；强行拆散只改变座位与课程，不改写已有关系。

## 9. 家庭共识与沟通方式

家长支持、学生意愿、学业风险与经济条件分别讨论。外出费用太高不代表家长反对 OI，文化课担忧也不代表学生不愿努力。

一次共识会记录：当前目标、每周可投入时段、费用上限、休整条件、考试安排、复查日期。教练只能承诺自己能控制的行动，如提供复盘和调整日程，不能承诺录取与必获奖。

谈话可采用“先听原因”“共同列计划”“明确边界”三种结构，内容由已有证据决定，不存在对所有人都最优的温柔或严厉按钮。同类谈话沿用七标准日冷却；紧急安全沟通不受冷却限制，但不重复获得恢复效果。

## 10. 承诺的执行与到期

承诺不是点击选项后的立即奖励。它包含负责人、对象、行动、截止日期、可验证完成条件和无法完成时的改约方式。

例如“下周给你一次单独讲评”：先生成待确认预约，真正执行一时段讲评后完成。若比赛改期冲突，提前改约可保留信任；过期不解释则留下失约。对象离队时将其转为交接或告别事项，不让日程永久阻塞。

对同一问题，同一教练每周只能承担一项主要承诺，避免玩家把所有选项都选“我保证”。承诺清单可合并提醒，不能自动代替玩家确认花钱或取消正式赛。

## 11. 故事调度与内容密度

以下故事是条件驱动内容库，不要求每名学生每年全部遇到。主要随机抉择沿用事件文档每学年 3～6 个的节奏；既有链的复查节点不重新占一个独立故事名额。

每条链使用学生 ID 和具体证据绑定，触发后固定实例，不通过读档换一名更有利的主角。普通干预至少保留七标准日，健康紧急情况可先暂停训练。正向发展来自完成行动，不保证下一场考试一定逆袭。

### 11.1 故事与事件卡共享实例

人物故事是同一诉求的展开方式或延期后续，不是另一套同时发奖励的事件系统。先以 cause_key 识别具体证据来源，再检查互斥组；命中既有实例就把故事挂到该实例，不重复创建主要抉择、承诺、费用或日程。只有不同事实来源的独立诉求才能另开实例。

| 人物故事 | 关联主卡或专属入口 | 互斥组 | cause_key / 共同承诺键 |
|---|---|---|---|
| story_fast_thought_slow_hands | 专属实现节奏入口；与E01/E05引用同一失分证据时并入原卡 | training_habit | 学生ID+失分证据批次 / implementation_plan |
| story_label_pressure | 专属公开期待入口；E09已处理同一目标压力时作为上下文 | public_expectation | 学生ID+宣传或目标记录ID / expectation_review |
| story_grade9_crossroads | E08；已有E07家庭共识时沿用该毕业规划实例 | graduation_plan | 学生ID+毕业学年 / graduation_agreement |
| story_equal_scores_one_seat | E27及名额分配链；没有游说时直接进入选拔节点 | quota_allocation | 名额批次ID+候选组合 / allocation_procedure |
| story_quiet_maintainer | 专属工作量入口；若同一项目触发E25，则并入岗位冲突处置 | student_workload | 学生ID+项目或排班ID / protected_training |
| story_one_more_week | 专属公开问题探索入口 | personal_project | 学生ID+问题族ID / research_milestones |
| story_mentor_handover | 专属毕业交接入口，E29作为该实例的毕业后回访节点 | alumni_contact | 师徒组合ID+毕业学年 / mentor_handover |
| story_camp_cost_concern | E11，营费与车票是同一行程资金问题的细项 | travel_funding | 学生ID+行程ID / travel_funding_plan |

互斥组不同也要先查同一 cause_key 是否已经被处理；不能靠换一个组名绕过去重。一个实例只有一份有效选择、承诺状态、冷却起点和主要额度记录，人物对白可以更新但结果不重结算。名单、日期或费用真的改变时创建原实例的更正节点，保留先前事实，不从“第一次决定”重新发奖励。

## 12. 故事一：脑子比手快

**ID：story_fast_thought_slow_hands。** 触发：同一学生连续两场模拟赛的主要失分都是“思路完成、编码未提交”，其思维观察明显强于编码观察，当前没有健康紧急风险。

选择 A：安排两周共四个实现练习时段，每次限定先写可靠基础版本，再逐步优化。使用指定题单的正常成本与 XP，替换原本的可选训练。选择 B：先把下场策略改为保部分分，保留现有课程。选择 C：询问是否愿意暂缓比赛，改为一周常规训练和休整。

第七日检查练习是否真的执行；第十四日给一份未见题族作迁移评估。A 的进展表现为实际实现证据与耗时改善，B 更可能留下完整低档提交但不提高知识等级，C 缓解竞赛日程压力但少一次比赛样本。

下一场仍按真实能力算分。若学生离队，关闭训练承诺并保留“还没来得及写完的解法”作为阶段档案；不给完成故事固定 +10 编码。

## 13. 故事二：别再叫我天才

**ID：story_label_pressure。** 触发：学生近期被公开宣传或连续承担过高目标，压力至少 70，且出现“害怕让大家失望”的谈话线索。

选择 A：撤回未经本人同意的个人宣传，改成团队成果；耗一个沟通行动，必要时调整后续宣传任务。选择 B：与学生重谈可控的过程目标，占一谈话时段。选择 C：暂时维持原安排，但必须公开说明不保证名次，并设七日复查。

七日后检查宣传是否撤回、目标是否真正改变。实际减少外部要求时，压力来源消失后按状态规则逐步恢复；不立刻清零。维持安排可能继续积压压力，也可能经本人确认后稳定，依据现有状态与承诺结果判定。

若宣传项目已经结束，不再收撤回费用；转为赛后澄清和隐私偏好设置。故事完成后保存本人今后是否愿意公开姓名，未来活动再次确认。

## 14. 故事三：初三最后一周

**ID：story_grade9_crossroads。** 触发：初三学生进入毕业规划窗口，文化课压力升高，下一场比赛资格与学校衔接情况已知。

选择 A：暂停竞赛训练，明确中考后复谈时间。选择 B：在学校与家庭允许的范围内保留一小段兴趣练习，移除高强度集训。选择 C：确认退役，安排一次告别复盘和资料交接。

七日内先确认日程与家长共识，三十标准日或下一毕业节点检查去向。A 不承诺必返队，B 不绕过学业或资格要求，C 保留已获成绩与未来学长联系。不能因为关系高就把中考和升学选择跳过去。

若去往不提供高中培养的学校，解除未执行本校计划；有合作学校也要重新确认注册。已退役不在三十日复查中自动恢复在队，回归必须走生命周期规则。

## 15. 故事四：同分的两张准考证

**ID：story_equal_scores_one_seat。** 触发：两位符合资格的学生争取一个尚未分配的校内可选席位，近期成绩接近，已有公开选拔办法。

选择 A：按已公布办法执行，提供事实解释。选择 B：若规则原本允许加赛，安排加赛并支付实际时段；不能在结果已知后新增偏向一人的题目。选择 C：若席位允许，申请额外观察机会，但不在批准前承诺成功。

当日先锁定程序，七日内完成允许的选拔与个别沟通。被选者可能感到压力，未被选者可能失落，数值变化依据比赛与谈话事实，不固定把一人变成反派。

若席位突然撤销，两人都进入政策通知与替代安排，不把责任算给另一位学生。已消耗名额不因友谊值高而复制；选拔结果确认后不能用重复抽签改写。

## 16. 故事五：总在帮别人修电脑的人

**ID：story_quiet_maintainer。** 触发：学生多次帮助整理测试、记录故障或协助同伴，但自己的训练经常被这些事务挤占。

选择 A：承认贡献，并为其保留正常个人训练，维护工作交给合格技术员。选择 B：经本人同意安排一个公开的测试项目，计入实际练习或教研时段。选择 C：让其在不参赛的校内活动担任一次志愿者，同时明确责任边界。

七日后检查“恢复个人训练”是否真的兑现，十四日后由本人选择是否继续承担辅助角色。贡献可以进入校史、项目署名与学长兴趣，不直接等价为竞赛加分。

正式参赛学生不能同时担任接触秘密题与评测环境的工作人员；未成年学生也不能被当作无限免费的技术雇员。若没有替代人手，就减少活动规模，不默认继续占用此人的全部时间。

## 17. 故事六：这道题我还想再想一周

**ID：story_one_more_week。** 触发：学生对一个已公开难题提出自己的猜想，已有可展示的初步反例或实验记录，下一重要赛事不在不可调整窗口。

选择 A：批准一个二十一日内、共三个练习时段的小项目，要求产物是证据与解释。选择 B：先参加当前训练，再预约赛后一周继续。选择 C：说明近期时间不足，把材料存入个人项目档案，允许以后重开。

第七日查看问题是否更清楚，第十四日决定继续或缩小范围，第二十一日展示“证明、反例、失败方法清单”之一。没有证明成功也可完成有价值的项目，但知识收益只来自实际练习和讲评。

项目不能调用未解密赛题。学生退役或毕业时允许以公开资料移交，接手者须重新确认，不把前一人的完成证据算成下一人的独立首做。

## 18. 故事七：学长说过会回来

**ID：story_mentor_handover。** 触发：一对正式师徒中，指导者即将毕业，学弟学妹仍依赖固定指导，双方过去至少完成两次有效活动。

选择 A：安排一次交接讲评，留下知识缺口、资料和学习方法。选择 B：联系另一位愿意接手的在队学生，安排三方确认。选择 C：经学长本人允许，预约毕业后一次回访，但说明档期不保证。

毕业前七日完成交接检查，毕业后三十日只检查联系方式与预约状态；大学生活尚未稳定时允许改约。免费回访计入学长每学年主要无偿支援次数，不能给同一师徒无限回校课。

无人接手时改为教练定期复查，不直接让学弟学妹大幅掉经验。学长失约会影响具体承诺，但不抹去过去指导的贡献，允许后续解释与修复。

## 19. 故事八：我们家不想再交营费了

**ID：story_camp_cost_concern。** 触发：外出集训报价超过家庭约定预算，家长提出费用顾虑，学生仍希望学习；不要求低家庭财富标签才能触发。

选择 A：改为校内免费题库与同等时段训练，保留原学习目标。选择 B：若学校有已批准的公开补助，按条件申请，等待审核期间不先报名欠费。选择 C：放弃这次外出，安排一次目标沟通并寻找后续公开机会。

七日内在报名截止前确认路线，三十日后复查实际训练是否落地。校内方案不保证与名师营完全同等收益，但不会因为没有付营费直接削减天赋或学业。

补助来自实际预算或明确赞助合同，不能凭同情生成现金。名单按事先公布条件处理，学生是否愿意公开受助情况单独确认。若外出项目取消，退款与原支付方对应，不把家长已付费用退入学校可支配现金。

## 20. 离开、重逢与长期回声

离队时至少提供“最后一次成绩”“想留下的话”“愿意保持的联系”三个可选片段；不强制每个人写煽情毕业信。沉默、简短告别和以后才回信也是有效表达。

多年后回访可以引用确实发生的记忆：某次共同修掉的 Bug、一张旧题单、一次尊重休整的决定。引用使用稳定事件 ID 和事实，不根据当前奖牌数量临时编造过去。

失败与遗憾同样能进入校史，但只记录本人允许公开的信息。公众荣誉墙和教练私人档案分开；家庭经济、健康细节和私人谈话不因成为学长而自动公开。

## 21. 关系系统验收

同一故事实例只结算一次；所有承诺对应真实活动；对象离队有回退；师徒不得循环加成；高关系不能绕过名额资格；无反馈赛气泡不泄露真实分；同一条小事不无限累积永久惩罚。

内容试用时重点观察：玩家是否能分清学生自己的诉求与家长期望，是否存在明显“全选同一句鼓励”最优解，是否有不花钱也能维护关系的路径，以及离队是否保留尊重与继续经营的空间。
