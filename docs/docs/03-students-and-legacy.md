# 学生、招生与传承

[返回 README](../README.md) · [训练规则](02-time-and-training.md) · [事件与政策](06-events-and-world.md)

学生的价值由成长与经历体现。招到天才不应直接结束经营问题，暂时落后也不应等价于“无用学生”。本篇为正式赛季阶段的默认草案，MVP 仅实现固定测试学生及基础状态。

## 1. 学生档案与可见信息

| 信息层 | 内容 | 展示方式 |
|---|---|---|
| 已知事实 | 年级、入队时间、出勤、已参加比赛、确认的奖项 | 直接显示 |
| 训练观测 | 知识熟练度、编码、细节、心理和近期趋势 | 初次观察显示区间，样本积累后收窄 |
| 私人目标 | 学生目标、家长期望、学业压力的原因 | 通过谈话逐步了解 |
| 隐藏信息 | 未揭示天赋、成长曲线、RP | 用行为线索提示，不提供精确潜力排名 |

训练计算使用真实值，界面展示观察估计；两者必须分开保存。MVP 为调试方便可直接显示真实值，调试面板明确标识。

每条档案至少包含稳定 ID、姓名、年级、世代、入队日期、生命周期状态、属性、知识、目标、家长支持度、关系、历史成绩和事件标记。姓名可以重复，引用必须使用 ID。

## 2. 招生流程

~~~text
招生计划 → 候选名单 → 试训与沟通 → 发出邀请 → 学生及家庭确认 → 注册入队
~~~

- 9 月为主要窗口，转学生是独立的小概率事件；不能反复刷新候选池。
- 候选池在招生季开始时生成并持久化，同一候选人整个窗口使用同一个 ID。
- 招生计划包含人数上限、年级结构、预留机位和基础训练安排；确认邀请前展示预计月度开销。
- 初一至高一可正常招新，高二、高三的转入属于专门事件和规则，默认不开放普通招生。
- 试训包括基础知识、实现练习和一次谈话，分别提供不同信息；一次考试不能揭示全部天赋。
- 正常撤回邀请保留原因与沟通成本。反复邀请再拒绝不能刷新人才或赚取关系。

### 2.1 人数与资质

正式开局为 6 人：初一 3 人、初二 2 人、初三 1 人。原型的 10 人为固定测试名单，不占用正式招生配置。

“可招人数”同时受学校授权容量、可服务机位和教师教学容量限制。12 个机位槽只有 8 台健康电脑时，同一时段最多安排 8 人上机，其余人可错峰或参加其他活动。接近容量上限时先提示资源缺口，不自动扩建。

### 2.2 初始分布与世代差异

首轮可用有界三角分布生成基础属性：最低 25、众数 50、最高 75。极端天赋、不同年级和背景通过配置修正，统一限制到 0～100。

- 每人默认抽取 1～3 个不冲突的天赋；相反天赋互斥，例如同一维度的“细节狂魔”和“粗心大意”。
- 世代标签只对部分属性或兴趣作小幅偏移，默认不超过 5 点；不让某一届整体必然强于上一届。
- 家庭财富影响可承担的外出费用与事件背景，不直接提高思维或学习力。
- 罕见成长曲线提供成长节奏差异，不承诺必然获奖；准确曲线不在招生日直接公开。
- 年级较高的候选人带有更多已学知识和训练经历，同时剩余培养时间更短。

候选人数、稀有天赋比例和声誉修正均待试训后校准。声誉优先增加可接触候选数量，避免高声誉只生成高属性学生的单向滚雪球。

## 3. 生命周期状态机

~~~mermaid
stateDiagram-v2
    [*] --> 候选
    候选 --> 试训
    试训 --> 在队: 双方确认
    在队 --> 暂停训练: 休整或学业安排
    暂停训练 --> 在队: 复谈并确认返队
    在队 --> 离队协商: 毕业或持续退队意向
    暂停训练 --> 离队协商: 确认离队
    离队协商 --> 在队: 非毕业情况达成新计划
    离队协商 --> 已退役: 确认退出竞赛
    已退役 --> 毕业校友: 完成学段或升学
    毕业校友 --> 学长网络: 建立联系
~~~

“暂停训练”仍是注册成员，可以安排文化课与休整，但不能自动参加集训。已经正式退役的学生不通过一次谈话直接回到在队；回归只能走明确的例外规则并重查资格。

未确认入队的候选人可以在招生窗口结束后离开候选池，保留邀请记录。毕业校友是否保持联系与竞赛成绩分开；已退役但尚未毕业的学生仍可留在学校参加普通活动。

## 4. 年级推进与退役窗口

- 9 月 1 日执行升年级，之前完成上一学年的毕业、退役与校史结算；同一学生同一学年只推进一次。
- 初三安排中考沟通窗口；进入高中是否继续，取决于学生去向、家庭意愿和学校是否提供高中培养。
- 6 月开启毕业与赛季结束规划。退役的实际日期由最后一场符合资格的比赛、本人决定和毕业节点共同决定。
- 高三不默认可以参加 7 月赛事，系统先读取赛事规则包；无资格时直接进入毕业规划，不生成“必须等 NOI 后退役”的任务。
- 最长在队 6 个学年；跨校转入保留既有年级和经历，不能重新计算为初一。
- 比赛已经报名但学生离队时，先处理退赛和规则允许的替补，再释放日程与名额。

原稿中“初三约 50% 退役”是人口结构的平衡目标，不是每次到达某个日期便进行一次 50% 即时淘汰。应由家庭、学业和目标共同驱动，并通过多年模拟观察实际留存率。

## 5. 留队意愿、家长与预警

建议使用四个独立指标：学生留队意愿、家长支持度、学业风险、健康风险。家长支持度采用 -100～100，其余采用 0～100；任意一个指标变化不直接覆盖其他指标。

| 情况 | 先给玩家的信息 | 可采取的行动 |
|---|---|---|
| 连续两周学业低于约定目标 | 学业趋势、缺课和家庭提醒 | 调整训练比例、安排文化课、重谈目标 |
| 连续两场重大失利 | 学生自述、压力与信心变化 | 复盘错因、降低目标、暂缓比赛 |
| 高倦怠或睡眠不足 | 训练收益下降、休整建议 | 放假、减强度、处理压力来源 |
| 收到外校或机构邀请 | 邀请内容与学生关切 | 改善培养计划、允许交流、接受离开 |
| 毕业临近 | 最后赛季与升学清单 | 规划最后一赛、交接学弟学妹 |

默认预警流程为“观察 → 提醒 → 协商 → 确认”，普通风险至少留出 7 个标准日的干预窗口。健康紧急事件可以立即暂停训练，但不直接销毁学生档案。

谈话的效果取决于是否解决具体问题。同一承诺失约会降低信任；连续点击鼓励不应成为无限恢复心情的方法。尊重离队也是有效选择，不将所有离队都记为教练失败。

## 6. 分组与传帮带

- 分组依据当前知识前置、训练目标和可用时间，不提供永久的“优生组 / 差生组”标签。
- 每周可调整分组；移动学生时预览其课程是否适合、是否产生场地冲突。
- 结对活动一位学长默认带一位学弟学妹，只有双方出勤才生效。
- 指导者在该时段牺牲部分个人训练收益，获得沟通或复盘能力成长；被指导者收益需要指导者确实掌握对应知识。
- 师徒收益同一时段最多结算一次，不能通过互相指定循环倍增。
- 友谊和竞争关系按实际互动积累，比赛分差只影响近期压力，不自动抹去长期友谊。

## 7. 升学、退役与学长网络

退役结算生成不可变的阶段档案：入队与离队日期、已确认奖项、代表比赛、师徒关系、离队原因和玩家寄语。更正历史成绩时保留更正记录。

升学是一组条件和意愿共同决定的去向事件；奖牌只满足条件之一。具体政策来自当前年度规则包，不把“拿金牌”硬编码为自动保送。

| 学长角色 | 解锁条件示例 | 约束 |
|---|---|---|
| 回校讲课 | 愿意联系、具有对应知识、时间允许 | 占用教室和时段，不覆盖现有课程 |
| 题目作者 | 有命题经历、题目完成验收 | 赛题保密与查重仍有效 |
| 助教 | 毕业到适当阶段、双方签订聘用 | 独立薪资、教学容量和精力 |
| 捐赠人 | 关系、经济状况及事件条件满足 | 资金到账一次，附带要求写入合同 |
| 外部联络 | 进入高校、企业或组织后 | 提供公开机会，不保证录取或违规席位 |

学长每学年最多触发一次主要无偿支援，多个学长支援设总量上限；关系维护有时间成本。成熟校队可提高稳定性，但不能靠历史规模无限刷钱。

## 8. 校史与代际交接

校史记录首次获奖、设备扩建、承办、师徒传承、退役与毕业。常规日志按年聚合，重要节点保留完整条目。

年终提供三类回顾：学生自己的变化、教练的决策影响、下一届的资源缺口。比如“本届三名高年级离队，图论方向只剩一名熟练学生”，比单独展示声誉 +5 更能引出下一年的计划。

学生全部离队时，学校进入恢复流程，保留教练经验、校史和学长关系，补充到 3 名保底学生及可用基础机位。补充不会制造高稀有天赋，也不重复发放开局资金；见[经营文档](05-economy-and-hosting.md)。

## 9. 典型学生故事与验收

| 场景 | 预期行为 |
|---|---|
| 学习力高但细节低 | 知识成长快，比赛仍可能挂分；能通过调试与复盘改善 |
| 初三学生希望暂停半年 | 保留档案和关系，按高中去向决定是否返队 |
| 高三报名不符合资格的赛事 | 报名前明确阻止，不到比赛日才淘汰 |
| 学生退役后保存、读取两次 | 学长档案、奖项和离队奖励不重复生成 |
| 家长支持度高但学生热爱低 | 仍需沟通本人目标，不自动视为长期留队 |
| 只剩一届高年级 | 招生与交接面板提前揭示断档风险 |

## 10. 人物内容的进一步展开

性格、记忆、承诺、家庭共识和八条完整人物线见[关系与故事](12-relationships-and-student-stories.md)。退役、暂停和毕业仍使用本篇生命周期；故事是同一事实的展开，不能另建一套“剧情在队”绕过资格。

[个人成长](23-talents-and-personal-growth.md)进一步定义天赋发现、八种成长曲线和能力周结算。隐藏天赋在生成时固定，揭示不新增槽位；能力练习证据每人每标准时段最多1点，不能通过拆分活动刷取。

[年鉴与校史](18-achievements-and-player-expression.md)只使用允许公开的档案与素材。公开荣誉、私人谈话和玩家自写回忆分开存放，匿名不会抹去合法经历。
