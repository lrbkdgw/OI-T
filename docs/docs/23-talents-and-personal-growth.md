# 天赋、成长曲线与能力训练

[返回 README](../README.md) · [学生系统](03-students-and-legacy.md) · [训练规则](02-time-and-training.md) · [关系故事](12-relationships-and-student-stories.md)

本篇增加 36 个可制作的天赋候选、成长曲线与永久能力训练细则。均为扩展草案：正式学生仍只有 1～3 个天赋，隐藏天赋不是额外无限槽位，成长曲线单独记录。阶段 2 接入少量天赋，完整发现与周结算在赛季和内容阶段逐步加入。

## 1. 天赋不代替学生经历

天赋描述某一环节的习惯或相对优势。学生可以通过训练改善弱项，但不因一次大赛失利就被重新随机分配“粗心”或“考场失忆”。性格、兴趣、目标、知识和家庭依旧独立存在。

不把每个负面天赋都做成必须换人的永久缺陷。环境演练、提交清单、带教和休整能降低某些问题的影响；是否改变天赋本身要经过明确的长期事件，不靠付费刷新。

## 2. 生效环节与叠加规则

| 环节 | 可以修改 | 不允许再重复修改 |
|---|---|---|
| 知识成长 | 适用标签的T因子 | 同时又给相同理由的基础XP加成 |
| 构思 | 有界能力修正、明确重试节点 | 每分钟重新掷骰直到成功 |
| 编码 | 基础耗时与环境适应 | 正式评测机速度 |
| 错误 | 总挂分率或错误类型分布之一 | 两个环节对同一种效果重复降低 |
| 自测 | 耗时、可发现的错误类别 | 没有实际错误也刷调试收益 |
| 决策 | 选题偏好、止损、检查分配 | 赛中读取不可见分数 |
| 协作 | 实际带教与讨论证据 | 全队常驻无限光环 |

知识成长 T 的总乘积仍限制在0.6～1.5；其他修正采用所属模型的上限。每个生效记录保留来源天赋，解释面板只公开已揭示部分，未揭示时使用“个体学习习惯”描述。

## 4. 互斥、组合与成长曲线

细节狂魔与原稿的粗心大意互斥；tal_clutch（大心脏）与 tal_exam_freeze（临场迟滞）明确允许共存，分别作用于压力项与陌生环境首阶段耗时；某些看似相反但作用不同的组合可共存，例如编码快与选题慢。

36项是候选制作库，不代表同一规则包全启用。将原稿同义天赋映射到稳定 ID，例如“调试大师”映射 tal_debugger；改显示名不重新生成天赋。学生隐藏与已揭示数组引用同一组天赋，不能把揭示当作新增槽位。

| 成长曲线 | 体验 | 周能力成长因子C草案 | 约束 |
|---|---|---|---|
| 稳定型 | 节奏稳定 | 全程1.0 | 不代表潜力最低 |
| 早熟型 | 入队基础较好 | 前两在队学年1.1，之后0.9 | 初始优势在生成预算内，不能另送全知识 |
| 大器晚成 | 需要更长观察 | 前两年0.9，之后1.1 | 不在高三突然保证获奖 |
| 缓慢起步 | 对新环境适应慢 | 前60标准日0.85，之后1.05 | 休息和离队不重置60日刷加成 |
| 阶梯型 | 复盘后更明显进步 | 默认0.95，完成真实瓶颈任务后连续28日1.15 | 冷却一学期，不重复叠窗口 |
| 专项型 | 某类练习更有效 | 指定能力1.1，其他0.95 | 只作用于能力周结算，不重复乘知识XP |
| 自主型 | 获得合理自主空间后稳定 | 履行本人计划时1.05，否则1.0 | 不是不受教师和资格规则约束 |
| 适应型 | 环境稳定后改善 | 重大迁移后28日0.9，随后回1.0 | 用于故事，不让频繁搬座位制造成长奖励 |

成长曲线 C 不再乘进已有知识 XP 公式，避免同一学习优势同时膨胀两套数值；它只影响下面的永久能力周成长。

## 5. 如何发现天赋

每个候选维护“线索—观察—确认”状态。生成时已经确定真实天赋，后续观察决定玩家知道多少，不是在谈话时再随机抽一个更强的天赋。

线索来自可比活动：同难度、相近状态、同类环境中反复出现的模式。单次高分、失败或主观抱怨不能直接确认。老师可以选择一节诊断活动，代价是占用真实时段，不消耗一笔神秘鉴定费。

老师对学生的估计可以错误，但最终确认要有足够证据；记录置信与更正历史。学生不会因为教练误判标签而改变真实属性。

## 6. 永久能力的练习证据

永久能力包括思维、编码、细节、心理，以及调试、应试策略、部分分策略、卡常技能。学习力的长期变化另用明确故事或年度成长，不靠每日刷题直接无限上涨。

| 目标能力 | 有效证据 | 不计入的行为 |
|---|---|---|
| 思维 | 独立建模、正确说明新解法、有效反例 | 完整照抄题解 |
| 编码 | 合法时段内独立实现适合难度的解法 | 反复提交相同代码 |
| 细节 | 执行检查后确实发现并修复边界 | 仅勾选“我检查过” |
| 心理 | 压力下完成本人认可的可行策略并复盘 | 故意制造连续羞辱或熬夜 |
| 调试 | 找到真实错误并解释最小反例 | 自己重复注入同一错误再修复 |
| 应试策略 | 合理题序、明确止损、有效提交 | 赛后知道答案再宣称本来就会 |
| 部分分策略 | 独立设计并实现可验证的低档解法 | 只选中“保底”按钮 |
| 卡常 | 有复杂度前提的测量与优化 | 本校换高配后误以为正式赛更快 |

每名学生每个标准时段最多提供1点练习证据，可分给至多两个能力，份额总和不超过1；同段全部子活动合计受此上限约束。跨时段比赛按实际占用逐段计，不能按每次提交发点；知识 XP 与能力证据是不同产物，不互相复制数值。

## 7. 周结算默认公式

~~~text
p = 本周已验证的某能力练习点
x = 该能力当前值，0～100
C = 当前成长曲线因子
Δx = min(0.5, p/20 × (1 - x/120) × C)
x_new = min(100, x + Δx)
~~~

例：编码50、本周10点、稳定型C=1，则增长约0.2917；编码90且同样10点时增长0.125。高水平仍能成长，但不会与新手一样每周跳数点。每周0.5是单能力上限，不因多个天赋再突破。

这是能力训练初版候选速度，需通过多年模拟验证。天赋表里未明确作用于证据点的效果，不能自行再给p乘系数；更快编码可能让学生完成更多实际练习，但每时段上限仍然生效。

## 8. 周期、存档与离队

周结算以连续标准日每七日一个边界，不能每次跨月重新发一次。360日学年包含51周与3天，末尾3天证据结转到下一周，换学年不复制。

记录活动证据唯一ID、能力份额、是否已结算、当前周起点和余量。读档、改班、临时休整不重置上限。退役时可结算本周已有合法证据并归档；之后不再每周持续发成长，回归例外也不能重新领取旧证据。

基础属性减少只用于明确定义的长期机制或事件，不把普通低分直接转换为永久思维下降。疲劳恢复后，状态影响消退，已学能力仍在。

## 9. 组合算例

“数学直觉+过目不忘”用于一项70%数学、30%其他的复合练习。先将基础收益按标签分份；数学份额乘1.15×1.30=1.495，其他新知识份额乘1.30，不把整题都乘1.495。若再加其他因子超1.5，按每份适用T上限截取。

“手速怪+边界迟钝”让学生更快写完，但仍可能在空集和端点上出错。更早完成可以留出自测时间，是否降低实际失分取决于是否选择检查，不直接把两项效果抵消成一个综合战力。

“大心脏+冲顶倾向”可能在压力中稳定做难题，也可能因为选择过高目标没交出保底。性格和天赋提供故事方向，不保证结果正面。

## 10. 可改善的弱项与长期任务

学生反复因文件名丢分，可制定三场检查任务；环境陌生可安排两次演练；慢实现可做限时拆分练习。任务写清观察期、活动与评价，不设置“交钱消除负面天赋”。

达到任务条件后，优先更新习惯与实际能力。只有确实是可变的适应标签，才将天赋效果改为已适应状态；真正稳定倾向保留，学生学习如何与之相处。

任务失败没有永久锁死的惩罚。学生可以调整目标或换路径；“承认自己不喜欢高强度竞赛”也可以形成完整成长故事。

## 11. 内容制作与调试

每个天赋实现前写清生效环节、范围、上限、互斥、发现证据、解释文本和回放表现。只说“偶尔变强”“提高运气”不够进入配置。

调试页可以显示真值、已知值和证据来源，但正式UI只能显示玩家有权知道的信息。新增天赋时用无反馈赛与读档场景检查，防止一个“反馈敏感”特性读取后台真实评测或让读档重新抽灵感。

## 12. 验收与未决问题

需要覆盖：标签份额和等于总XP、T上限、36项互斥配置、每时段证据上限、周跨月跨年、退役结算去重、已揭示天赋不复制、陌生环境适应状态，以及同种子在不同倍速下得到一致灵感结果。

待定的是不同曲线的实际分布、稀有天赋供给、周成长是否过慢、长期弱项能改善到何种程度。先用少量学生完整跑过至少一个赛季，再扩展全部36项；不把候选库规模当作第一阶段实现承诺。
