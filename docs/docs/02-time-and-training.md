# 时间、训练与成长

[返回 README](../README.md) · [设计总览](01-game-design.md) · [比赛模拟](04-competition-simulation.md)

本篇定义日常循环的默认草案。目标是让排课产生可解释的收益，让休息、分组和复盘都有机会成本。

## 1. 时间与日历

| 项目 | 默认规则 |
|---|---|
| 学年边界 | 9 月 1 日开始，次年 8 月 30 日结束，随后进入新学年 |
| 日期编码 | 使用学年、月序 0～11、日序 0～29；月序 0 对应 9 月，不直接使用公历日期运算 |
| 时段 | 上午、下午、晚自习、夜间；夜间默认睡眠 |
| 1× 时长 | 每日 600 现实秒，默认每个时段 150 秒；表现时长不代表四段现实钟点等长 |
| 暂停与倍速 | 暂停 / 1× / 2× / 5× / 10×；倍速只改变等待时间 |
| 比赛日 | 默认降到 1×，允许 2×；重大抉择维持暂停直到完成或明确委托默认选项 |

经营时段是一次活动结算的边界。比赛的 180、240、270 等“分钟”是独立的虚拟比赛预算；报名页面提前展示占用几个时段，不能由现实动画耗时推算。

跨月、跨年、学业考试、拨款、报名截止均是有稳定 ID 的日历事件。把同一天的多个提醒合并展示，但逐条记录结果。

## 2. 时段结算顺序

1. 接收并校验已提交的日程变更、报名与建造命令。
2. 处理当前边界已到期的规则变更、名额有效期和强制日程；同一边界政策变更先于资格校验。
3. 对本时段活动重新检查人员、机位、教练、预算和前置知识，并锁定资源。
4. 生成执行快照，计算学习、活动消耗、设备使用和比赛子步骤。
5. 写入属性、知识经验、现金与设备状态，形成一次不可重复提交的结算事务。
6. 处理结算后触发的事件、关系变化和通知，推进到下一个时段。
7. 若为日末，再结算月费、学业趋势、退役预警等对应周期事项；自动存档后暂停或继续。

强制抉择在步骤 2 或步骤 6 出现时，停在已完成的事务边界，不能让时段结算一半。事件不能递归触发无限个事件，队列规则见[事件文档](06-events-and-world.md)。

## 3. 排课与资源冲突

每项活动记录参与学生、负责人、场地、占用时段、知识点、强度与预算。学生同一时段只能参加一个活动；同一教练不能同时讲两门课。

- 一个小组同时开课最多受可用机位和教师教学容量限制；纸笔讲解可改用教室，但编码练习仍需电脑。
- 机房的槽位、已安装设备、健康设备和正式考场可用机位分别计数。
- 正式赛、学业考试、已确认的外出行程先于普通模板；在确认前列出受影响的训练安排。
- 冲突活动保留为“待安排”，不自动移动到深夜。普通训练不能执行时默认改为监督自习或休息，并记录原因。
- 钱、精力或负责人不足时不得静默借款、聘人、透支。透支必须由玩家主动打开；强制休息和基础学业活动始终可选。
- 拖拽排课只是计划，时段开始后锁定；尚未执行的后续时段可以修改。

## 4. 活动成本与收益

以下为每个标准时段的基础变化，结算后统一限制到合法范围。教师精力与学生体力分开计算。

| 活动 | 教练精力 | 学生体力 | 疲劳 | 压力 | 基础知识 XP | 主要用途 |
|---|---:|---:|---:|---:|---:|---|
| 讲课 | 20 | -12 | +8 | +3 | 20 | 学习新知识，受前置与难度影响 |
| 指定题单 | 5 | -15 | +10 | +2 | 16 | 巩固知识、练实现和调试 |
| 自主刷题 | 0 | -10 | +6 | +1 | 12 | 自主选择方向，存在偏科 |
| 模拟赛 | 15 / 场 | -25 / 时段 | +18 / 时段 | +10 / 时段 | 0 | 先检验能力，知识收益放在讲评 |
| 赛后讲评 | 15 | -8 | +5 | -4 | 18 | 针对真实错因，修复错误理解 |
| 文化课 | 0 | -8 | +4 | -3 | 0 | 改善学业趋势，挤占竞赛时间 |
| 自由休息 | 0 | +18 | -12 | -6 | 0 | 恢复状态，心情基础 +5 |
| 夜间睡眠 | 0 | +35 | -25 | -5 | 0 | 日常恢复；每夜只执行一次 |

模拟赛监考精力只在开赛时扣一次，跨时段的学生消耗按实际占用计；中断后重开面板不能重复扣费。个人谈话消耗教练精力 10，作为该时段负责人行动，最多覆盖 2 名学生；参与学生的主活动改为谈话，不叠加完整训练收益。

教练每日开始恢复到当前精力上限，默认 100；主动透支最低可到 -20。当日后续由该教练负责的教学系数 ×0.7，次日精力恢复额减少透支量。无教练值守的活动不受该系数影响。助教使用独立行动预算。

## 5. 知识经验与学习公式

### 5.1 等级与经验

每个知识点保存**累计 XP**，等级由阈值计算，避免等级与经验各自更新产生矛盾。

~~~text
从等级 k 升到 k+1 所需 XP = 100 + 50k，k = 0…9
累计阈值：Lv.0 = 0，Lv.1 = 100，Lv.2 = 250，Lv.3 = 450
Lv.10 累计阈值 = 3250，达到后不继续堆叠无效经验
~~~

界面可显示“等级 3，距下一级 120 / 250”，存档仍以累计 XP = 570 为准。总览中旧式 lv / xp 示例的 xp 解释为级内经验，导入时转换为累计 XP。

### 5.2 成长公式

~~~text
本时段 XP = 基础 XP × 学习力 L × 状态 S × 难度 M × 设备 E × 教练 C × 天赋 T
L = 0.5 + 学习力 / 100
S = clamp((0.5 + 体力/200) × (0.5 + 心情/200) × (1 - 疲劳/200), 0.2, 1.0)
E = 对应场地训练系数，默认 1.0，首轮范围 0.8～1.2
C = 有负责人时 clamp(0.8 + 讲课能力/200, 0.8, 1.3)；自主刷题取 1.0
T = 适用天赋乘积，限制在 0.6～1.5
~~~

公式读取**活动开始时**的状态，活动结束再扣体力、加疲劳。普通训练不抽取额外随机成长，方便玩家理解同一日程的收益差异。

授课难度采用 0～10 的知识等级尺度，d = 授课难度 - 学生当前等级：

| d | 难度系数 M |
|---|---|
| d < 0 | 0.3 |
| 0 ≤ d ≤ 1.5 | 1.0 + 0.2d |
| 1.5 < d ≤ 2 | 1.3 - 2.2 × (d - 1.5) |
| d > 2 | 0.2；额外降低心情 5～15，按差距取确定值 |

例如：基础 XP 20、学习力 66、体力 80、心情 70、疲劳 20、d = 1.5、设备 1.0、讲课能力 60、无天赋时，获得约 **22.84 XP**。内部保留至少四位小数，界面显示两位，不能每次截断为整数。

### 5.3 前置知识与题单

- 知识图是无环图，边记录最低要求，如“前缀和 Lv.1 → 差分”；具体依赖属于内容配置。
- 未满足前置时可试听，XP 再乘 0.25；界面给出缺失项。首次引导不推荐此类课程。
- 题单按知识覆盖与目标难度匹配，不能依靠反复刷同一道已掌握的题获取满额经验。
- 同一道题第一次独立完成按正常 XP；复做基础收益降为 20%，用于复习；查题解后的立即提交不算独立完成。
- 一场比赛只在首次讲评时产生完整知识收益；重复打开成绩单或重复播放回放不产生收益。
- 复合题把总 XP 按知识点权重分配，不能让每个标签分别获得完整 XP。

## 6. 疲劳、压力与倦怠

体力、心情、疲劳、压力、倦怠均为 0～100，但含义不同：体力是当前精力，疲劳是近期透支，压力来自目标与竞争，倦怠反映长期失衡。

- 连续两个高强度时段后，第三个高强度时段的体力消耗 ×1.25；跨天不自动清零，完成睡眠或半天休息后清零。
- 夜间训练替代睡眠，不能同时获得夜间恢复；夜猫子只改善夜间效率，不取消睡眠需求。
- 日末疲劳 ≥70 或压力 ≥80 时，倦怠 +2；当日至少一个自由休息且疲劳 <40 时，倦怠 -1。
- 倦怠 ≥60 时发出预警，≥80 时触发休整协商；不因单日触线直接永久退队。
- 体力 ≤15 时不能安排高强度训练，已排计划降为休息；强制赛程遇到健康冲突时提示缺席或允许的退赛流程。
- 谈话缓解特定原因，不能立刻清空疲劳和倦怠；同一学生同类谈话冷却 7 个标准日。

基础属性与比赛技能的永久成长按“有效练习量 + 复盘证据”累计，每周结算一次，不能用大量零成本提交刷属性。具体成长速度先作为可调参数，首轮只实现知识 XP、体力、疲劳和心情。

## 7. 遗忘与复习

同一知识点连续 14 个标准日没有有效练习后，每日累计 XP 衰减 0.3。经验下限对应等级为：历史最高等级为 0 时取 0，否则取 max(1, 历史最高等级 - 1)。例如历史最高 Lv.3、累计 XP 570 时，最低只衰减到 Lv.2 的累计阈值 **250 XP**；曾达到 Lv.1 的知识不退回 Lv.0。衰减只扣除高于下限的经验，不补发经验。

复习重置未练习天数；遗忘扣除量写入日志。考纲调整影响题目权重和训练选择，不直接删除已学经验。该机制为后续功能，MVP 可关闭，但存档预留最后练习日期和历史最高等级。

## 8. 精简模式的等价规则

精简模式显示 120 个可操作日，每个对应 **3 个连续标准日**。界面仍编辑四个时段，默认将模板重复应用到这三个标准日；内部逐个标准时段结算，而不是一次把收益乘 3。

- 固定映射为每月 10 个可操作日，第 n 日覆盖标准日期 3n-2、3n-1、3n。
- 每日精力恢复、夜间睡眠、冷却、遗忘、工资和风险检定按标准日执行。
- 报名截止、比赛和抉择落在区块中间时，暂停在真实标准边界。剩余部分可修改，不额外发放完整区块收益。
- 重大赛事替换对应标准时段；不因重复模板而重复报名或比赛。
- 同一标准日程、种子和操作在两种模式下运行，应得到相同模拟状态；差别来自玩家每次观察与操作的频率。

标准模式一年在 1× 下约 60 小时、10× 下约 6 小时；精简模式对应约 20 小时和 2 小时。以上只计算自动推进，不含暂停、操作与比赛限速。

## 9. 边界与验收

| 场景 | 应有结果 |
|---|---|
| 同一计划分别用 1× 与 10× 推进一周 | 学生、资金、设备、随机流状态一致 |
| 模拟赛占两时段，下午已有课程 | 提交前展示冲突，确认后课程变为待安排 |
| 教练精力只剩 10，安排讲课 | 未授权透支时拒绝；休息、自主刷题仍可执行 |
| 一道题带三个知识标签 | 三个标签分到的 XP 之和等于本题总 XP |
| 精简区块第二个标准日报名截止 | 在截止边界前提醒，不跳到区块结束才处理 |
| 时段提交后立刻重复发送命令 | 不重复增长、不重复扣费 |
