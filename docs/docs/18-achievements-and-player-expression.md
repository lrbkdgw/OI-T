# 成就、校史与玩家表达

[返回 README](../README.md) · [学生与传承](03-students-and-legacy.md) · [界面体验](07-ui-and-onboarding.md) · [开局与难度](17-scenarios-and-difficulty.md)

本篇定义 48 项可核验成就，以及奖杯、年鉴、照片、校服、机房主题与校史回顾的制作流程。全部为未实现的设计草案：基础教学与比赛成就从阶段 3 接入，经营和承办分别从阶段 4、5 接入，传承从阶段 6 接入，表达内容在阶段 7～8 完善。它们不扩大固定机房 MVP 的范围。

成就提供观察与纪念的角度，不提供永久属性、现金或隐性参赛加分。装饰解锁没有付费购买假设，学生能力仍由训练与状态系统决定。失败、暂停、退役和没有奖牌的经历也能进入校史。

## 1. 成就判定的统一语义

“完成活动”指活动成功结算并有出勤与产物；打开面板、生成计划、答应帮助均不算完成。“比赛结果”指复核结束后的正式版本，不以临时榜单发奖。“不同题目”按题目及版本来源识别，简单改标题不能刷新计数。

“连续一学年”指 360 个标准日，而不是精简模式下 360 个可操作日；精简模式 120 个区块仍可完成同样观察窗口。“至少一个”必须有真实样本，“全员无错误”不能通过无人参赛或零提交完成。

成就进度由只读事实汇总，不通过额外事件反复加计数。默认进度在游戏存档内，跨剧本的 ach_explore_08 另使用下述本机成就档案。存档保存成就 ID、规则版本、完成时间、证据引用与适用模式；新版本可以更正展示，但不得悄悄改写旧档的完成事实。

## 2. 资格分类与自定义模式

| 分类 | 允许的开局与设置 | 保存与展示 |
|---|---|---|
| 通用经历 | 合法场景、标准或特色开局、任何体验设置 | 显示实际场景、难度和完成日期 |
| 规则挑战 | 满足表内观察窗口且没有相关资源辅助 | 附适用规则版本与完整窗口 |
| 沙盒纪念 | 自定义资源或中途直接改状态 | 仍可记录、拍照与做年鉴，标“沙盒记录” |

更换 UI 缩放、色觉辅助、提醒密度、暂停偏好不影响资格。中途改变未来难度不撤销之前奖项；需固定难度的挑战只对其明确窗口重新检查。额外赠款影响财务挑战，直接增加学生能力影响培养和成绩挑战，修改外观不影响两者。

资源辅助不应使所有校史丢失：例如沙盒中毕业的学生仍有真实经历，可以制作年鉴。标准规则成就和沙盒纪念使用不同标记，避免看似同一枚奖章却对应完全不同的资源条件。

### 2.1 跨剧本的本机成就档案

ach_explore_08 是本机级经历，不要求单个存档同时绑定两个剧本。新建世界生成稳定 world_id 与 root_world_id；复制存档保持两者，年度快照分支可以有新 world_id，但沿用原 root_world_id。场景ID和版本在该世界创建后固定。

完整学年归档时生成包含 root_world_id、world_id、scenario_id、scenario_version、学年ID、规则版本与归档摘要的完成证据，游戏档和本机成就档案各保留一份。以 root_world_id+scenario_id+学年ID 去重；同一根世界复制、恢复或开分支不算另一次独立开局。达到两个不同特色场景ID、各来自独立根世界的一学年证据后确认成就。

本机档案有独立版本和备份，不需要账号、网络或上传。丢失时可以从仍在的年度归档证据重建已知条目；缺失的另一世界不靠猜测补齐。合并只增加有来源的证据，不重新发放游戏内收益，也不改变任何学校资金与学生状态。

## 3. 教学成就：让成长看得见

| ID | 名称 | 可检查条件 | 范围与最低样本 |
|---|---|---|---|
| ach_teach_01 | 第一块垫脚石 | 一名学生某知识从 Lv.0 达到 Lv.1 | 同一档案，有实际 XP 事务 |
| ach_teach_02 | 因材分组 | 同周两组各完成至少两次前置满足、d 在 0～1.5 的课程 | 每组至少2人，非同人重复组 |
| ach_teach_03 | 复盘有下文 | 比赛中确认一种知识缺口，14日内完成对应讲评与新题练习 | 同学生一条完整证据链 |
| ach_teach_04 | 会休息的队伍 | 连续30日未主动安排夜间训练，至少每周一次休息 | 至少3名注册学生、正常教学出勤 |
| ach_teach_05 | 一题多解 | 同一学生对3道不同题各完成两种合法解法的学习记录 | 非重复提交刷计数 |
| ach_teach_06 | 反例收藏家 | 产生并保存10个不同错误来源的最小反例 | 对拍证据通过校验，不要求制造新错误 |
| ach_teach_07 | 前置铺好了 | 一学年内开设的全部新知识课程均满足参与者前置 | 至少12次课、4种知识、3名学生 |
| ach_teach_08 | 交给他也能讲 | 学生实际带教2次，对方完成独立新题练习 | 同一对学生，指导者有相应知识 |

以上不鼓励教练故意反复把课程排得过难再修复；条件只读自然训练记录。主动保存反例没有额外 XP，解锁贴纸也不能提高下一次调试概率。

## 4. 比赛成就：过程与结果同时记录

| ID | 名称 | 可检查条件 | 范围与最低样本 |
|---|---|---|---|
| ach_contest_01 | 交卷了 | 完成一场有最终评测的传统题比赛 | 至少1人、至少1份有效提交 |
| ach_contest_02 | 第一份完整解答 | 一名学生单题最终得分达到满分 | 非空题、规则正常、未直接改分 |
| ach_contest_03 | 部分分也有价值 | 同场至少两题获得非零且非满分，学生总分高于任一单题满分 | 正常提交过程与真实子任务 |
| ach_contest_04 | 给检查留点时间 | 连续3场执行预设最后15分钟检查，且有完整检查记录 | 每场实际剩余并使用时间，不要求必修出Bug |
| ach_contest_05 | 第一次榜上有名 | 在一个正式奖项榜单获得任意有效奖项 | 复核结束、规则包有奖项 |
| ach_contest_06 | 各有长处 | 同场3名学生分别在不同题取得本队最高分 | 至少3题，允许并列但不能三人所有题全同分 |
| ach_contest_07 | 熟题不选人 | 发现熟题的内部选拔在开赛前更换题目并重新公告 | 全体遵守同一新快照 |
| ach_contest_08 | 依据而不是运气 | 完成一次有证据的复核程序并收到正式裁定 | 裁定成功或不支持均可，不要求人为制造错评 |

奖牌颜色、全国参赛与更高排名可作为奖杯档案字段，不必为每一种数值复制大量成就。无反馈赛中不得提前弹出“满分已达成”；所有相关解锁等到正式结果允许公开时再显示。

## 5. 经营成就：稳定比刷收入更有意义

| ID | 名称 | 可检查条件 | 范围与最低样本 |
|---|---|---|---|
| ach_manage_01 | 第一份月报 | 结束一个完整月并查看收支和下月已知支出 | 月账有实际收入或支出 |
| ach_manage_02 | 留有余地 | 连续6次月结现金足以覆盖未来30日已知必要费用 | 无直接赠款辅助，至少3名学生正常训练 |
| ach_manage_03 | 物尽其用 | 将一件闲置普通设备检验后投入有效用途 | 同物品ID，不含保底设备商业化 |
| ach_manage_04 | 逐步扩容 | 完成一次分期扩建，施工期间没有未处理教学冲突 | 有真实工期、付款与验收 |
| ach_manage_05 | 看得懂的账 | 连续12次月结所有金额都可追溯到合法事务 | 无未分类的大额支出、无重复事务 |
| ach_manage_06 | 按时付清 | 一学年全部必要账单在到期前支付 | 至少12次月结、没有删除债务辅助 |
| ach_manage_07 | 旧机房新用途 | 一间原机房通过改造变为另一个实际使用场地 | 有验收和至少3次有效活动，不只是换名字 |
| ach_manage_08 | 小而稳定 | 注册人数3～8人，连续3学年完成教学与年度总结 | 每学年均至少3名有实际出勤学生 |

“摆脱预警”可以作为特定剧本里程碑，不为故意欠债再偿还提供循环奖励。主动保守、缩小规模或接受合法保底不会抹去学生故事，但严格财务挑战应明确记录援助种类与观察窗口。

## 6. 承办成就：奖励规范的组织过程

| ID | 名称 | 可检查条件 | 范围与最低样本 |
|---|---|---|---|
| ach_host_01 | 欢迎来到我们的机房 | 第一项获批承办从申请走到归档 | 非演示假项目，实际对外参与者至少10人 |
| ach_host_02 | 备用不是摆设 | 验收满足规则备用比例，且备用机全部可用 | 项目正式验收，不能故意造故障 |
| ach_host_03 | 角色分得清 | 同一项目全部敏感岗位无参赛身份冲突 | 有真实工作人员名单与岗位 |
| ach_host_04 | 公告同步 | 一项需要更正的公告按规则同时送达所有受影响组 | 自然发生更正，有送达记录；不强求出现 |
| ach_host_05 | 钱款对得上 | 项目预拨、尾款、运营、资本支出与退款分别核清 | 归档后无重复领款和未解释差额 |
| ach_host_06 | 一个标准对所有人 | 项目所有实际事故依统一流程处理 | 至少1次真实事故，没有则等待未来自然机会 |
| ach_host_07 | 合法的名单 | 至少一次有两名以上候选的席位分配完成公告与资格检查 | 名额批次有效，不通过复制席位满足 |
| ach_host_08 | 下次再见 | 连续3项外部承办最终评级不低于A | 每项有真实规模与人员，间隔和工期合法 |

成就不会为了完成条件强制生成事故。玩家可以永远不遇到某个自然条件，也不因此少拿资源；未解锁只表示缺少这段经历。演练可生成独立“演练完成”校史记录，不冒充真实事故裁定。

## 9. 奖杯、铭牌与荣誉室

奖杯来自真实正式赛事结果，成就徽章来自本篇判定，纪念物来自特定经历。三者在外观和说明上区分，不能把“完成一次讲评”的徽章装成 NOI 金牌。

流程为“选择一项有效记录 → 选择展示样式 → 预览铭牌 → 选择房间位置 → 确认保存”。铭牌显示名称、时间、对应规则包和人物或匿名称谓，可附玩家自写寄语。改写寄语不改变奖项事实。

荣誉室占物理空间，柜体若需购买则只有布置成本；不因奖杯数量直接提供训练系数。展示容量满时可轮换或存入档案，隐藏奖杯不撤销成就。源成绩更正后铭牌同步标注更正，旧照片保留当时画面并增加说明。

退役学生可选择“第一次写出暴力”“修好了机房门”“带学弟看懂 BFS”等纪念卡，来源必须是已发生事件或玩家明确标为自写回忆。自写回忆不参与事实型成就计数。

## 10. 年鉴编辑器

### 10.1 素材与页面

年鉴按学年建立，默认页序是封面、成员、年度时间线、比赛与训练、生活片段、交接与毕业、教练寄语。素材来自已公开档案、照片、比赛记录、事件摘要和玩家文字，不直接抓取隐藏数据。

每页使用有限模板：合照页、双人故事页、四事件时间线、比赛结果表、空白寄语页。玩家能替换照片、调整顺序、删去不愿展示的条目；模板应自动避开长姓名和过多队员造成的溢出。

### 10.2 编辑、校验与产物

输入为“年度ID、被选素材ID、文字、匿名与展示授权设置”，编辑产生可继续修改的草稿。预览时检查缺失图片、无效人物引用、隐藏赛果、未经允许的家庭信息和未完成去向。

通过校验后可以保存本地静态网页或图片册，未来是否提供 PDF 由实现阶段决定；当前文档不承诺现有导出工具。导出的年鉴包含生成时间、档案版本和“游戏内虚构记录”说明，不包含未公开的家庭财富、精确隐藏天赋和世界随机流。

原始素材更正时草稿显示“来源已更新”，已导出文件作为当时版本保留。重复导出不会重复解锁成就、产生收益或消耗活动时间。

## 11. 照片模式与年度合照

照片模式暂停或冻结表现层，不能冻结一半模拟事务。可调整镜头、人物可见性、时间表现和框线，调整后不改变实际天气、日期、状态或出勤事实。切换“摆拍”时在照片元信息中标记，不冒充真实赛事现场。

合照可以按实际年度名单生成站位，毕业、暂停训练和非公开身份分别以适当标记处理。个性动作来自角色已有动画，不需要让学生真实熬夜或累病才能拍疲惫表情。

截图默认隐藏调试层、悬浮隐私说明、真实隐藏分数和本机文件路径。输出本地图片后由玩家决定是否分享；保存图片不自动上传，也不发送给任何外部联系人。没有开启照片功能时仍能保存年鉴文本。

## 12. 校服、校徽、标语与房间主题

校服编辑使用有限色板、基础款和挂件槽。不同年级仍保留清楚可辨的轮廓，不让复杂服装覆盖状态标记。徽记采用预制形状组合和文本，不要求 AI 生成图像或导入外部素材。

标语可以写在机房墙、队服背面或年鉴封面，限制长度并提供换行预览。例如“先拿稳能拿的分”“先睡一觉再调”均是视觉表达，不改变部分分或睡眠数值。玩家文字与事实记录分别保存，不能用标语冒充系统公告。

房间主题包括旧机房、明亮教室、木色自习室、夜间工作站等。主题只变材质、装饰和灯光表现；真正改善舒适度需要购置并运行对应功能设施。主题不能用一张空调贴图代替空调设备，也不凭装饰更改考场资质。

稀有装饰可由成就解锁使用资格，摆放可需要普通布置操作，但不附永久成长加成。所有装饰都可在安全边界移除，不因换皮破坏已保存日程和资产计数。

## 13. 校史时间线与“回到那一年”

年度归档聚合招生、训练转折、代表比赛、经营建设、承办、退役与毕业。回顾可按某个学生、世代、知识方向或房间筛选，帮助玩家看到一次决策如何影响后续。

“回到那一年”首先是只读展示：读取年度快照，重建当时可公开的场景和报表，不直接恢复成为当前可操作档。玩家若要从快照另开分支，必须明确另存新档，并标记分支来源；原校史与奖励不会跨档转移。

完整比赛回放只使用已记录的提交和评测版本，事件摘要不够时显示静态复盘，不虚构逐分钟操作。多年存档可聚合普通活动，仅保留关键证据与人物引用，避免为了回顾保存每一帧。

## 15. 数据、撤销与内容验收
