# 学校经营、承办与名额

[返回 README](../README.md) · [比赛模拟](04-competition-simulation.md) · [开发验收](09-development-plan.md)

经营系统的目的，是让投入方向、现金储备与培养目标形成取舍。初期不要求靠随机赞助维持生存，后期也不应无限依赖卖设备或承办补贴刷钱。金额均为游戏内货币单位。

## 1. 预算基线与现金流

正式新档现金 30,000，秋季与春季各拨款 20,000。**开局 30,000 已包含当期秋季拨款**，9 月 1 日不额外发一次；下一次常规拨款在次年 3 月 1 日。

以下为 Lv.1、6 名学生、无收费外聘人员的示例月预算：

| 支出 | 金额 / 月 | 说明 |
|---|---:|---|
| 水电与网络 | 600 | 基础场地成本；新增空调等按实际增量另计 |
| 设备日常维护 | 400 | 旧设备预留；实际故障维修另列 |
| 资料与题库 | 300 | 基础订阅 |
| 福利与耗材 | 200 | 可调，但削减会影响环境与心情 |
| 合计 | **1,500** | 不含外出、报名、扩建和突发维修 |

在不额外投入的对照情景下，两个学期拨款合计 40,000，12 个月基础支出 18,000，年度经常收支差为 **+22,000**。这只是现金流基线，不是玩家必得净利润；扩大队伍、聘助教和承办比赛会明显提高支出。

按开局口径，第一个学年结束现金为 30,000 + 20,000 - 18,000 = **32,000**，不能再加一次秋季 20,000。设备购买是现金支出，折旧是非现金账面记录，两者不能重复扣钱。

## 2. 交易、预测与支出约束

- 每笔账记录日期、事务 ID、收支类别、对象、实际金额和来源事件。
- 已收到补贴、未到账应收、已承诺支出和可自由使用的现金分开显示。
- 未来 30 / 90 个标准日预测仅计已知固定项，随机奖金与赞助单列为不确定收入。
- 批量采购先校验整单；默认整单成功或失败，不购买一半后留下无法完成的建设。
- 普通消费不能让现金低于 0；已经签约的费用及必要账单可形成应付欠款，并触发财务处理。
- 可选贷款必须明确本金、利率、还款日期和抵押范围；未确认的推荐预算不产生实际支出。
- 设备出售按状态折价，默认回收价低于购买价；获得保底援助的设备不可出售。

## 3. 设施、容量与设备故障

| 名称 | 定义 |
|---|---|
| 机位槽数 | 房间能摆多少完整上机位 |
| 已安装机位 | 主机、显示器、输入设备和座椅齐全的数量 |
| 健康机位 | 当前可正常训练使用的已安装机位 |
| 考场有效机位 | 通过网络、电力、环境等检查的健康机位 |
| 正式参赛容量 | 满足备用机要求后可安排的参赛人数 |

正式开局 12 槽、8 台可用旧电脑，服务 6 名学生。学校等级提供授权容量上限，建筑提供物理容量，两者共同约束扩招。

认证考点如接受 N 人，要求有效机位数至少 N + ceil(0.1N)。例如 30 名考生需要 **33 台**符合要求的电脑，不能把 30 台参赛电脑中的 3 台同时当作备用。

设备故障率按月配置，但按标准日检定。月故障概率 p 转为日概率 q = 1 - (1-p)^(1/30)，避免精简模式或倍速造成风险变化。故障设备在维修前不重复抽同一故障；维修成功后恢复检定。月概率是“持续可用的设备在 30 日内至少发生一次故障”的基准。

高配设备降低故障、提高训练效率；正式赛评测性能遵循赛事环境，不由本校采购价格决定。UPS 的“30 分钟”指虚拟事故持续时间，不是 30 个现实分钟。

## 4. 财务预警与软失败

| 阶段 | 触发条件草案 | 处理 |
|---|---|---|
| 储备提醒 | 现金不足未来 30 日已知必要支出 | 给出费用清单、缩减建议，无惩罚 |
| 财务预警 | 存在逾期账单，或连续 2 次月结有未付必要费用 | 暂停非必要采购与新承办申请，形成整改目标 |
| 整改期 | 预警持续 3 次月结仍未清偿 | 降低授权规模，处置非保底闲置设备，协商合同 |
| 恢复运行 | 欠款清零且连续 2 次月结有正储备 | 恢复采购与申请，逐步恢复授权规模 |

净现金流为负不等于破产；有充足储备时允许建设期赤字。界面区分本月亏损、现金不足与已经欠款。

最差状态保留 3 名学生的基础训练条件、教练、校史、基础机房与免费题库。援助先补足必要教学条件，再由学校直接承担这部分保底运营费用，不向可支配现金发放可刷取的补助。

保底设备不可出售、抵押或用来产生商业承办收益；保底支持不支付贷款、罚款、扩建和外聘合同。旧欠款保留并协商分期，冻结的可选合同按明确规则退出，不通过删除债务无限借款。

## 5. 声誉与学校等级

学校声誉、教练声誉、圈内口碑和外部关系分开结算。一次获奖不应同时让所有指标按同一公式上涨。

学校等级建议采用最近 3 个赛季的加权评分：最近一年 50%、前一年 30%、再前一年 20%。评分维度包含培养成果、教学稳定、财务健康与承办记录，权重待测；不能只看历史奖牌总数。

连续两个赛季低于降级线才普通降级；重大违规可直接暂停相应资质。已经建设的设施保留，新增招生容量、承办资格和拨款系数可能受限。声誉与成绩对拨款的总乘数首轮限制在 0.5～2.0，保底支持单独计算。

## 6. 承办状态机与预算

~~~text
可申请 → 已申请 → 评估中 → 获批 → 筹备 → 验收 → 比赛日
                                               ↓         ↓
                                            整改/撤回   结算 → 归档
~~~

每次状态切换保存负责人、截止时间、已完成检查和费用。申请失败、撤回、不可抗力取消和违规停办使用不同的退款及处罚规则。

### 6.1 筹备要求

申请前显示硬性门槛与竞争评分：硬件、备用机、电力、隔离网络、人员和场地不合格时不能靠关系分覆盖。通过门槛后，历史记录、服务质量和外部关系影响竞争结果。

筹备任务包括设备验收、环境校准、网络压测、监考培训、应急演练和接待。经费充足不能瞬间完成有工期的任务；教练参与筹备会挤占训练与谈话。

### 6.2 认证考点预算示例

| 项目 | 金额 | 结算时点 |
|---|---:|---|
| 申请费 | -1,000 | 提交申请，不退 |
| 运营筹备 | -12,000 | 分任务支付 |
| 补贴预拨 | +10,000 | 获批后到账 |
| 补贴尾款 | +5,000 | 通过验收并完成结算后到账 |
| 净现金变化 | **+2,000** | 假设全部完成且无额外事故 |

15,000 补贴是预拨与尾款之和，不能在获批和结算时各发 15,000。新购服务器、UPS 和扩建费用另列为资本支出，不包含在这 12,000 运营预算中。若另买 20,000 的服务器，本次现金变化变为 **-18,000**，设备留给后续使用。

预算页面至少展示总成本、各阶段最低现金、补贴到账条件和取消时的退款义务。不能只展示最终可能盈利而隐去筹备期间资金缺口。

## 7. 比赛日、公平与结算

- 同类故障采用统一换机、补时和记录流程，不允许单独为本校选手重评或看题。
- 处理事故消耗技术人员、备用机和时间；监考与技术人员分别计数，不能重复占岗。
- 承办评级依据准备、服务、公平和事故处置，不因本校获奖更多直接提升。
- 违规处罚按证据和裁定生成，不用随机“被抓到概率”作为规则允许与否的判断。
- 结算分别记运营现金流、资本支出、声誉、资质与名额，防止奖励被重复计入多个栏目。
- 本校对参赛选手的正式比赛规则见[比赛模拟](04-competition-simulation.md)，承办不能覆盖赛事资格校验。

## 8. 名额的类型与生命周期

每个名额批次记录：来源赛事、规则版本、类型、数量、适用赛季、候选资格、使用期限、是否可转让、是否可跨届、审批要求和当前状态。

~~~text
待确认 → 可分配 → 已预留 → 已使用
              ↘ 到期 / 撤销
~~~

- **参赛席位**：允许报名指定赛事，不保证获奖或晋级。
- **营员席位**：参加指定集训，不能换作正式赛资格。
- **观察与推荐资格**：只允许进入后续考察，不直接发放录取结果。
- **联盟交换席位**：仅在规则允许时跨校转让，保留原始来源和审批链。

默认不转让、不跨届、不到场不返还。需要报名审批的名额在报名阶段预留，批准后消耗；审批失败或截止前合规撤回才释放。超过截止期的弃赛是否返还由规则包决定。

分配时检查学生身份、年级、前置成绩、赛程冲突和其他已用名额。过期或撤销的预留先解除，再通知玩家重新选人；不能靠存档读取恢复已过期名额。承办考点示例的额外席位 +2 只是虚构规则包中的配置。

## 9. 经济与承办验收

| 场景 | 应有结果 |
|---|---|
| 新档推进到 9 月拨款日 | 不重复领取已包含在开局现金中的拨款 |
| 同一补贴到账事件重复执行 | 账本只有一次入账 |
| 30 名考生，仅 32 个有效机位 | 不通过 10% 备用机要求 |
| 卖掉全部非保底设备且无钱 | 进入恢复流程，仍有必要教学条件 |
| 名额已过期但仍在日程模板中 | 报名失败并指出有效期，不扣报名费 |
| 持有大量储备但本月净支出 | 只显示现金流减少，不自动进入整改 |

## 10. 扩展经营的计费边界

[校园建设](13-campus-construction-and-logistics.md)区分槽位、主机、配套、线路和验收。额外购买主机只在已有健康配套的前提下增加完整机位；施工和设备到货也不能立即视为可用考场。

[教师合同](11-team-staff-and-institutions.md)与[合作项目](15-sponsors-outreach-and-school-brand.md)属于基础月费之外的显式增量。公开课至少预留备课和授课，实物赞助不计可自由现金，限定基金不用于无关支出。

具体现金曲线、三年实例与借款候选见[数值专题](19-balance-and-multiyear-simulation.md)。场景套餐与可选合同不修改六人基线；同一服务若已含在套餐内，不能再次按另一专题全额扣费。
