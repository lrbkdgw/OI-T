# 数值体系、对照实验与跨年经营

[返回 README](../README.md) · [训练公式](02-time-and-training.md) · [比赛模型](04-competition-simulation.md) · [经营基线](05-economy-and-hosting.md)

本篇把“数值要认真”细化成可比较的决策案例。以下都是**设计期算例与实验方案**，并非已实现游戏的实测结果。基础规则仍以对应专题为准；本篇提出的额外成本和参数必须随扩展包显式启用。

## 1. 数值的五种用途

| 层次 | 解决的问题 | 不应承担的作用 |
|---|---|---|
| 资源 | 钱、时段、可用设备、教师精力够不够 | 用一个综合战力代替全部限制 |
| 状态 | 当前是否适合训练、比赛或休整 | 一次心情低就抹去多年积累 |
| 能力 | 已学知识、实现、调试、策略能完成什么 | 直接保证某种奖牌 |
| 规则 | 什么时间、什么人有资格做什么 | 用关系分绕过硬门槛 |
| 历史 | 学生和学校留下什么经历 | 将所有旧荣誉永久转化为无限乘数 |

不要让一个数字同时承担“当前状态”和“永久潜力”。体力低不降低知识累计 XP，学校声誉下降不删除已经取得的合法奖项。

## 2. 参数所有权与版本

| 参数族 | 权威文档 | 调参时一起观察 |
|---|---|---|
| XP、难度匹配、疲劳、休息 | 时间、训练与成长 | 等级速度、有效训练比例、排课负担 |
| 构思需求、码量、挂分、时间预算 | 比赛与评测模拟 | 得分分布、错因分布、策略差异 |
| 基础经费、设备、补贴、欠款 | 学校经营、承办与名额 | 最低现金、无随机收入存活率 |
| 家庭、目标、退役与代际 | 学生、招生与传承 | 年级结构、离队原因、玩家干预机会 |
| 课程、工作人员和设施扩展 | 对应扩展专题 | 对基础环节是替代、补充还是重复计费 |

每次调参形成一个规则包版本，注明变更项、预期体验、受影响存档和对照策略。不要同时调整全部系数后只凭“这次感觉好一点”接受结果。

| 档案 ID | 年级 | 学习力 / 思维 / 编码 / 细节 | 主要知识起点 | 初始关切 | 需要验证的玩法 |
|---|---|---|---|---|---|

| ref_fast_careless | 初二 | 72 / 68 / 65 / 28 | 二分、搜索 Lv.3 | 做得快但常挂分 | 检查时间与细节训练 |
| ref_slow_precise | 初二 | 50 / 58 / 35 / 82 | 前缀和、基础 DP Lv.2 | 知道做法却写不完 | 实现速度与题序 |

同一套课程不应对六人同样有效。若最佳做法始终是只培养最高思维学生，应检查队伍目标、低档部分分、师徒代价和招生期限，而不是硬塞一条“全员必须参赛”规则。

## 4. 一周训练对照：输入完整公开

测试对象采用学习力 66、讲课教师能力 60、无相关天赋、设备系数 1.0。起始体力 80、心情 70、疲劳 20、压力 35；同一知识累计 XP 为 0，固定课程难度 1.5。

- **计划 A**：每天上午、下午、晚自习都讲课，夜间睡眠，共 21 个教学时段。
- **计划 B**：每天上午、下午讲课，晚自习自由休息，夜间睡眠，共 14 个教学时段。
- 讲课与休息的变化使用训练文档表格；本例全部讲课设为高强度，第三个连续高强度时段体力消耗为 12 × 1.25 = 15。
- 每个活动以开始时的状态算 XP，之后更新状态；睡眠重置连续高强度计数。
- 达到等级阈值后立即更新等级，因此固定课程的难度匹配会变化；不自动提高课程难度。
- 此算例关闭事件、学业变化、技能周结算、遗忘与成长天赋，教练每天精力预算足够。

| 标准日末 | A 累计 XP | A 体力 / 疲劳 / 压力 | B 累计 XP | B 体力 / 疲劳 / 压力 |
|---|---:|---|---:|---|
| 1 | 61.25 | 76 / 19 / 39 | 43.21 | 100 / 0 / 30 |
| 2 | 118.67 | 72 / 18 / 43 | 98.44 | 100 / 0 / 25 |
| 3 | 168.61 | 68 / 17 / 47 | 151.10 | 100 / 0 / 20 |
| 4 | 217.58 | 64 / 16 / 51 | 200.49 | 100 / 0 / 15 |
| 5 | 255.36 | 60 / 15 / 55 | 251.23 | 100 / 0 / 10 |
| 6 | 268.18 | 56 / 14 / 59 | 265.43 | 100 / 0 / 5 |
| 7 | 280.72 | 52 / 13 / 63 | 279.99 | 100 / 0 / 0 |

A 在前两天更快进入 Lv.1，适合需要立即补基础的情境；七天后两者都进入 Lv.2。B 少上七节课，保留了更好的参赛状态。两者第六天 XP 都明显放缓，是因为 Lv.2 后继续上难度 1.5 的旧课，难度系数降为 0.3，提示教练应该换课程或转练习。

这不能推导出“每天都必须休息”或“讲课越少越好”：改变课程难度、初始状态、天赋和考试日期，最优安排都会变化。这个表的作用是检验公式能否解释结果。

## 5. 同等级为什么还能比赛差很多

接续上例，假设相关知识均为 Lv.2、思维 62、应试策略 45、RP 55，解法需求 D = 45，σ = 12。

~~~text
K = 20
A = 0.6×20 + 0.25×62 + 0.15×45 = 34.25
计划 A 日末心情 70，状态修正 B = -1.85
计划 B 日末心情 100，状态修正 B = 7.60
P_A = sigmoid((34.25 - 45 - 1.85)/12) ≈ 25.92%
P_B = sigmoid((34.25 - 45 + 7.60)/12) ≈ 43.47%
~~~

这是一次构思成功概率，尚未考虑编码时间、错误、自测和是否提交，不能直接当作题目得分率。玩家得到的结论应是“该学生有能力竞争，但状态拖后腿”，而不是“这场肯定拿 43 分”。

## 6. 训练之外的机会成本

同样的 20 点教练精力可以用于一节全组课程，也可以安排两次谈话。是否划算取决于人数和真实问题：

- 八人共同缺一个前置知识时，讲课可能优于逐人辅导。
- 只有一名学生因家庭冲突无法训练时，再讲一节课并不能解决出勤问题。
- 模拟赛后全队主要失分是未提交，增加高级算法课不如安排策略讲评。
- 机房只有八台电脑时，招到第九人可能需要错峰，而非立刻购买全新机房。

界面应把这些代价表现成“这次安排替换了什么”，而不是为每个活动随意定义一个价值分数后自动排序。

## 7. 设备投入的边际收益

训练设备 E 的首轮范围为 0.8～1.2。若旧设备取 1.0、中配取 1.1，在其余因子一致时，某次 20 XP 的训练增加到 22 XP；这不是属性永久 +10，也不是正式比赛运行速度 +10%。

示例额外假设：两处空槽已具备健康的显示器、键鼠和座椅，仅缺主机。在此前提下，两台低配主机共 5,000，可把实际可用机位从 8 提到 10；一台高配主机 8,000，只替换一个已有机位时，人数容量不增加。若当前主要问题是没有位置，前者可能更有用；若当前主要问题是反复故障，则要比较维护和更换。

“性价比”要同时看可用时段、人数、故障、房间槽位与资金缺口。没有报名需求时，买 20,000 服务器可能长期闲置；准备承办时，服务器也不能代替备用选手机。

## 8. 跨三学年的现金案例

本例只检验现金表，不预测获奖或自动升校级。基础年拨款维持 40,000，不假设随机奖金、捐赠或高声誉倍数；沿用上节“两个空槽配套齐全、仅缺主机”的算例前提。

扩招后的月运营套餐在本例取 1,500 + 125 × max(0,学生数-6)，是**扩展候选数值**，不改变基础六人套餐；设备采购、外聘和出行仍另付。每年学生数指年度稳定在队数，实际招生和退役必须另过生命周期校验。

| 项目 | 第 1 学年：6 人 | 第 2 学年：8 人 | 第 3 学年：10 人 |
|---|---:|---:|---:|
| 年初现金 | 30,000 | 22,800 | 25,600 |
| 本年新增常规拨款 | 20,000 | 40,000 | 40,000 |
| 公开体验课收入 | 0 | 0 | 6,000 |
| 基础运营 | -18,000 | -21,000 | -24,000 |
| 出行与报名 | -3,000 | -4,000 | -5,000 |
| 额外资料或体验课直接成本 | -1,200 | 0 | -1,600 |
| 两台低配主机 | -5,000 | 0 | 0 |
| 外聘预算 | 0 | -7,200 | -14,400 |
| 场地与线路局部改造 | 0 | -5,000 | 0 |
| UPS | 0 | 0 | -5,000 |
| 年末现金 | **22,800** | **25,600** | **21,600** |

外聘数额是本例可选择的年度合同预算，不给教师无限课时。第二年可用 1,200 × 6 个月、第三年可用 1,200 × 12 个月的受限兼职合同；具体能力、额度和替代人选按[教师团队专题](11-team-staff-and-institutions.md)匹配，不能在合同未供给时强行购买。

第三年 6,000 收入假设办六场每场 1,000 收入的纸笔公开体验课，直接耗材成本合计 1,600。每场各占教练一个备课时段与一个授课时段，六场合计十二个工作时段，且限定人数与场地；不允许在原本授课的同一时段再赚一场收入。它不等同于完整培训班，也不产生正式赛事资格。

如果第三年再买服务器 20,000，年末只剩 1,600。账面未必欠款，但储备很薄；若当期还有未计入的维修、差旅和合同尾款，就应推迟购买或重新排预算。没有满足机位和资质条件时，也不能因为买了服务器便申请认证考点。

## 9. 年末有钱仍可能中途缺钱

同样的年度净收支，到账时点不同会改变风险。以开局 30,000 为例：

| 时间 | 动作 | 动作后现金 |
|---|---|---:|
| 9 月 | 一次购买服务器 20,000 与 UPS 5,000 | 5,000 |
| 9 月月结 | 支付基础运营 1,500 | 3,500 |
| 10 月月结 | 再付 1,500 | 2,000 |
| 11 月 | 已确认报名与差旅需要 3,000 | 缺少 1,000，需取消、改期或明确借款 |

次年三月有拨款不代表九月就可以提前消费。未来收入预测应按日期绘制现金曲线，最低点比年末余额更值得关注。没有借款授权时，系统拒绝那笔可选消费，而非悄悄让现金变成负数。

## 10. 借款与长期成本

若规则包启用学校借款，可先用简单合同：本金 10,000、每 30 标准日按未还本金收取 1% 单利、不复利、最长 6 个月。首月末未还本金时利息为 100，先还 4,000 本金后，下一月利息为 60。

提前还款只减少未来利息，已结算利息不退。借款到账、偿还本金、利息费用分开记账；本金偿还不能再次算作经营损益。默认套餐不启用此合同，它只是用来验证“借钱争取时间”与“债务并没有消失”的可选机制。

进入保底支持不免除债务，也不允许出售保底电脑还贷款。必要教学条件由学校直接保障，其他资产和收入按整改计划处理。

## 11. 多年增长的反馈限制

| 正反馈 | 保留的爽感 | 需要的约束 |
|---|---|---|
| 成绩带来招生 | 能看到学校吸引力提高 | 更多候选，仍有有限教师与机位 |
| 声誉带来拨款 | 稳定经营更从容 | 总系数有上限，建设有持续成本 |
| 学长带来支持 | 过去的培养有回响 | 支援频率、时间和供给有限 |
| 承办留下设备 | 一次项目改善长期条件 | 资本支出、工期、资质和人员仍真实存在 |
| 高水平学生带人 | 传帮带缩短新生成长期 | 指导者牺牲个人活动，不循环加成 |

负反馈也要有缓冲：短期失利不立即掉级，学生离队留下档案而非全盘清零，政策更新给准备期。所有缓冲保留继续经营的空间，不保证玩家维持第一名。

## 12. 用策略组代替单一“标准答案”

建议的对照策略包括：均衡分组、只冲高年级、储备现金优先、设施优先、对外交流优先、学生自主优先。每个策略明确排课和支出规则，不由测试者临时挑选最有利操作。

例如“设施优先”定义为现金超过未来 90 日必要支出后，才购买能消除当前最大瓶颈的设备；不能定义成“永远买最贵设备”。“学生自主”仍要处理资格和健康底线，不等于永远不操作。

首轮每个策略使用同一批 20 个种子试跑，观察中位数与最差四分位；这是未来验证建议，不表示已有 20 局结果。单个传奇学生或一次低概率挂分不应主导整个结论。

## 13. 观察指标与反作弊取巧

| 指标 | 记录方法 | 常见误判 |
|---|---|---|
| 有效学习 | 每人每周实际 XP 与新增掌握范围 | 只看刷题提交次数 |
| 比赛进步 | 相近需求题组的错因与得分变化 | 不同难度试卷直接比较总分 |
| 留存 | 按毕业、兴趣、学业、健康分开 | 所有退役都当成经营失败 |
| 财务 | 最低现金、欠款、固定成本、净资产 | 把借款与未到账补贴当利润 |
| 操作负担 | 必须决策次数、重复排课时间 | 弹窗越多就叫内容越多 |
| 传承 | 下一届核心知识覆盖和可用导师 | 只看历史奖牌累计 |

检查刷法包括重复讲评、同题改名、先领补贴再取消、让学生反复退队入队、卖保底设备、通过精简模式缩短冷却、用装饰复制增益。修复应落在稳定来源 ID、事务和时间规则，不临时给玩家扣分。

## 14. 调参记录模板

一次实验至少写：规则版本、改动前后数值、种子集合、初始场景、策略描述、运行年限、主要指标、最差案例、可解释的原因和是否接受。

如果结论是“训练过快”，先判断是基础 XP 太大、难度一直自动匹配、熟题没有衰减，还是模拟赛反复送 XP。找到原因后只改相关环节，再用同一实验重复。不能用提高退休概率去抵消成长过快，让学生莫名离队。

## 15. 验收与待定

本篇算例必须能从公开输入重新计算。一周表不是引擎金标准：未来若活动成本经明确版本变更，更新算例并记录变更，不能为了匹配旧表保留已废弃规则。

尚待验证：永久属性每周增长速度、扩招后的实际边际成本、竞赛奖金幅度、不同难度下事件额度、长线声誉衰减，以及 120 可操作日是否足够保留学生故事。每项都应在对应系统接入后验证，不把整篇草案当作已经完成的平衡结论。
