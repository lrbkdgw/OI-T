# 游戏设计总览

[返回 README](../README.md)

本篇保留最初的 22 章策划结构。所有内容均为设计方案，数值为待验证草案；细化规则可从 [README 文档导航](../README.md#文档导航)进入对应专题。真实赛事与升学制度须以适用年度官方规则为准，此处采用游戏规则包。

## 1. 项目概述

**类型**：3D 像素风 / 上帝视角 / 经营模拟 + 养成 + 长线赛季
**定位**：玩家是一所中学的 OI 教练，要在有限的资金、时间和精力下经营机房、培养学生、争取名额、承办赛事，把一支小小的校队做成一所"OI 名校"。游戏**没有终点**，玩家想玩多少年就玩多少年。

**核心体验**
- **传承感**：学生初一入队，高三退役，学长回校讲课、捐赠、当外聘教练。你的队伍有历史。
- **取舍感**：讲课还是模拟赛，冲刺还是放假，名额给谁，要不要承办比赛。
- **OI 味**：AC / WA / TLE / RE、挂分、卡常、打表、对拍、骗分、AFO、拜神、"我是 flag"。
- **长线成长**：从没几台电脑的小机房，发展成省内强校，再到承办全国级赛事的主场。

---

## 2. 设计支柱

1. **时间是最稀缺的资源**：每一天、每一个时段都要做取舍。
2. **学生是活的人，不是数值**：天赋、性格、关系、家庭背景、出路都会影响故事。
3. **规则即玩法**：赛制、子任务、划线、名额分配都是玩法本身。
4. **没有终点，只有传承**：用世代、荣誉和变化的环境保持长期新鲜感。
5. **梗要有，但数值要认真**：幽默的表层下是可预测、可规划的系统。

---

## 3. 核心玩法循环

```
        ┌────────────── 年度赛程（CSP/NOIP/省选/NOI…）──────────────┐
        ↓                                                           │
 招生入队 → 日常训练（讲课/刷题/模拟赛/网赛/放假）→ 能力成长 → 参加比赛
        ↑                                           ↓
 声誉↑ 资金↑ 名额↑ ←────── 成绩/获奖/承办赛事 ←──────┘
        ↓
 购置设备、扩建机房、聘请外教、承办更高级别赛事 → 吸引更强新生 → 学生退役/升学 → 学长反哺
```

| 循环 | 周期 | 内容 |
|---|---|---|
| 短循环 | 天 / 时段 | 安排活动，观察学生，处理突发事件 |
| 中循环 | 月 | 月度模拟赛，复盘，财务结算，谈话 |
| 长循环 | 学年 | 招生、赛季、划线、退役、保送、名额分配 |
| 超长循环 | 多学年 | 世代更替、大纲更新、政策变化、学校等级提升 |

## 4. 视角与美术

### 4.1 视角
- 固定斜俯视上帝视角，可 90° 四向旋转、缩放，支持**剖面模式**（隐藏屋顶，便于看室内）。
- 可点击建筑进入"室内视图"，也可以拉远查看整个校园。
- **昼夜与季节**：夜晚灯光亮起，冬天飘雪，夏天有蝉鸣和空调外机。考前一周校园里有横幅，比赛当天有警戒线和彩旗。

### 4.2 像素与角色
- 体素或低分辨率贴图的 3D 模型，学生约 16~24 像素高。
- 外观随机生成：发型、眼镜、格子衬衫、卫衣、校服、书包、挂件。
- **年级外观区分**：初中校服与高中校服颜色不同。高年级随时间出现黑眼圈、发际线（梗）。
- 头顶气泡：💡灵感、💤困、😰紧张、🍜饿、🎮摸鱼、🔥状态火热、💀心态崩了、🙏拜神。
- 学长回校时有专属外观，如西装、大学卫衣、名牌 T 恤。

### 4.3 场景
| 场景 | 功能 |
|---|---|
| 机房 | 核心场景，训练、模拟赛、承办比赛 |
| 教室 | 讲课、讲评 |
| 教练办公室 | 查看名单、谈话、做计划、出题 |
| 走廊 / 操场 | 学生休息、聊天、放假活动 |
| 校门口 | 招生、访客、家长、机构人员、考生入场 |
| 宿舍区（解锁） | 影响睡眠与住宿类活动，承办赛事时可作选手住宿 |
| 食堂 / 小卖部（解锁） | 影响饮食、心情和体力 |
| 报告厅（解锁） | 讲座、开闭幕式，承办大型赛事必备 |
| 荣誉室 / 名人堂（解锁） | 展示历届奖杯、学长照片、获奖名单 |
| 评测机房 / 服务器间（解锁） | 承办赛事的核心设施 |

### 4.4 音乐音效
- 8-bit BGM：日常、模拟赛、考前紧张、比赛当天、颁奖、夜间安静各一套。
- 音效：键盘声、评测机"叮"声、AC 音效、WA 音效、TLE 的"滴——"声、空调声、风扇声、停电"啪"一声。
- 比赛倒计时最后 30 分钟，BGM 节奏加快，屏幕边缘出现红色脉动。

## 5. 时间系统

### 5.1 基础规则
- **10 现实分钟 = 1 游戏天**（1× 速度）。
- 倍速：**暂停 / 1× / 2× / 5× / 10×**，最高 10 倍（约 1 现实分钟 = 1 游戏天）。
- 一天分为 4 个时段：**上午 / 下午 / 晚自习 / 夜间**（夜间默认休息，学生熬夜需要玩家或学生自发决定）。
- 1 游戏月 = 30 天，1 学年 = 12 个月（360 天）。1× 约 60 小时，10× 约 6 小时。

### 5.2 年度日历（默认配置）

| 月份 | 事件 |
|---|---|
| 9 月 | 开学、招生季、**CSP-J/S 第一轮**（初赛）、学校拨款（秋季） |
| 10 月 | **CSP-J/S 第二轮**（复赛）、成绩公布 |
| 11 月 | **NOIP**、秋季集训 |
| 12 月 | 期末复习（学业压力上升）、冬令营报名、年度总结 |
| 1 月 | 期末考试、寒假开始、寒假集训、冬令营（NOI 冬令营） |
| 2 月 | 春节假期（家长干预多，学生状态波动） |
| 3 月 | 开学、春季拨款、省选备战 |
| 4 月 | **省选（联考）**、APIO 等 |
| 5 月 | 省队名单公布、省队集训、中考/高考冲刺（影响初三、高三学生） |
| 6 月 | 学期结束、学业考试、**退役窗口** |
| 7 月 | **NOI**、暑期集训、夏令营 |
| 8 月 | 暑假培训班、招生宣传、设备升级、**承办赛事筹备高峰期** |

### 5.3 自动暂停与提示
- 自动暂停：比赛前一周、比赛当天、学生退役、资金不足、学生状态异常、承办赛事突发事件、重大抉择。
- 玩家可在设置里分级调整：**全部 / 重要 / 仅危急**。
- 倍速限制在比赛、承办、抉择事件期间会自动降到 1×，可手动提升到 2×，不能 5× 以上，避免漏掉关键事件。

### 5.4 节奏控制
- **跳到下一事件**：连续快进，仍受 10× 上限约束。
- **长期计划**：如"暑假集训 30 天""寒假放假 7 天 + 集训 14 天"，按计划自动执行，遇到异常再提醒。
- **日程模板**：保存和调用"考前一周""日常周"等模板。
- **节奏模式**（开局选择）：
  - 标准：一年 360 天
  - 精简：一年压缩为 120 天（事件密度更高，每日精力消耗和成长按比例调整）

## 6. 长期运营机制（无结局）

本游戏没有结局、通关或失败画面，只有不断演进的"学校 OI 史"。

### 6.1 学校等级（长期成长主线）

| 等级 | 称号 | 典型状态 | 解锁 |
|---|---|---|---|
| Lv.1 | 兴趣小组 | 3~8 名学生，一间旧机房 | 基础设备、校内活动 |
| Lv.2 | 校级校队 | 10~15 人 | 参加区级比赛、基础题库 |
| Lv.3 | 区级强队 | 15~25 人 | 申请**认证考点**资质 |
| Lv.4 | 市级强校 | 20~30 人 | 承办市级联赛、初级夏令营 |
| Lv.5 | 省内名校 | 25~40 人 | 承办省选考点、省队名额倾斜 |
| Lv.6 | 全国知名 | 30~50 人 | 承办冬/夏令营、申请 NOI 承办 |
| Lv.7 | 竞赛名校 | 稳定产出奖牌 | 开设教练学院、基金会、联盟 |
| Lv.8+ | 传奇学府 | 学长遍布各大高校 | 无上限的声誉与"历史"系统 |

升级不是一次性成就，而是依据**近 N 个赛季的综合评分**浮动。成绩下滑会掉级，但有缓冲期，且保留已解锁内容。

### 6.2 软失败机制（只降级，不结束）

| 触发 | 后果 | 恢复方式 |
|---|---|---|
| 存在逾期账单，或连续两次月结有未付必要费用 | **财务预警**：暂停非必要采购与新承办申请，提供费用清单与整改目标 | 控制开支、安排收入、协商付款；现金充足的建设期净支出不触发预警 |
| 财务预警持续三次月结仍未清偿 | **整改期**：授权规模降低，处置非保底闲置设备，协商合同；保留必要教学条件 | 欠款清零且连续两次月结有正储备后，逐步恢复授权 |
| 成绩长期不佳 | 学校缩减名额、更换校领导，新领导有新的偏好 | 做出成绩，满足新领导的诉求 |
| 学生全部退役、无人入队 | **回到兴趣小组**，保底有 3 名学生和一间基础机房 | 重新招生，重新积累 |

> 保底规则：玩家永远处于一个"可以继续"的状态，最差状态是 Lv.1 的重新开始，并保留教练经验、学长网络与荣誉墙。

### 6.3 世代与传承
- **世代（Generation）**：以入队年份划分，如"2025 级"。每届有一个"世代风格"标签，如"数学强势""卷王一代""佛系一代"，影响该级学生初始分布和互动。
- **学长网络**：学长去向（清北、985、海外、工作）会产生长期回馈：
  - 回校讲课：免费高质量讲座，随机事件触发
  - 捐赠：设备、资金、基金会
  - 出题：为学校提供高质量题目
  - 内推：学弟学妹获得夏令营、实习或企业赞助
  - 外聘教练：学长做你的助教
- **荣誉墙 / 名人堂**：按学生、年份、奖项自动生成历史记录，可点击回顾学生当年的成绩曲线。
- **校史**：自动生成年度大事记，如"2031 年，首次承办省选考点"。

### 6.4 动态环境（防止后期无聊）
1. **大纲更新**：每隔几年出现新版考纲，增加新知识点或调整权重（如新增某类数据结构、某类数学内容），旧知识点价值变化。教练必须学习新内容，设备也可能需要升级。
2. **政策变化**：竞赛加分、保送、强基、综合评价政策松紧变化，直接影响家长态度、退役去向和招生热度。
3. **竞争学校成长**：AI 学校有自己的兴衰周期，会挖你的学生、抢名额、争夺承办权。
4. **题目 meta 变化**：某些年份流行"构造题""交互题""毒瘤数据结构"，需要调整训练方向。
5. **技术更新**：评测环境升级（语言版本、编译器、系统），旧设备可能不兼容，需要更新。
6. **市场变化**：机构兴起或衰落，影响招生来源和培训收入。

### 6.5 动态目标（非强制）
- 系统每学期提供 3~5 个"建议目标"，如"本赛季至少 3 人获省一"，完成得声誉和资金奖励。
- 玩家可以忽略这些建议，沙盒式经营。
- 长期成就（见第 17 章）提供额外的探索方向。

### 6.6 游戏阶段感受

| 阶段 | 游戏年 | 主要挑战 |
|---|---|---|
| 起步 | 1~2 | 活下去：钱少、设备差、学生少 |
| 成长 | 3~6 | 第一批高年级成长，拿到第一批奖，扩建机房 |
| 成型 | 7~12 | 稳定产出、承办赛事、名额运作 |
| 成熟 | 13~25 | 学长网络反哺，大纲/政策变化，竞争加剧 |
| 传奇 | 25+ | 维持声誉、传承、联盟、创造新纪录 |

## 7. 资金与经营

### 7.1 收入

| 来源 | 说明 |
|---|---|
| 学校拨款 | 每学期一次，基数 × 声誉系数 × 近期成绩系数 |
| 比赛奖金 | 各级比赛的获奖奖励、学校奖励、教育局奖励 |
| 企业赞助 | 触发于成绩、声誉或承办赛事；赞助商可能有附加要求，如冠名、必须参加某活动 |
| 校友捐赠 | 学长网络提供 |
| 培训收入 | 寒暑假校外班、周末班，消耗教练精力 |
| **承办补贴** | 承办各类赛事获得的经费补贴（见第 13 章） |
| 题库与出题收入 | 教练出题能力高时，可对外出售题目或为他校命题 |
| 家长捐助 | 学生成绩好、满意度高时触发 |

### 7.2 支出
- 设备购置、维护、折旧；电费、网费、空调费。
- 题库、资料购买（真题、模拟赛题包、数据包）。
- 外聘讲师、外校交流、差旅、报名费、集训营费用。
- 零食、饮料、福利、团建。
- 承办赛事的筹备费用（监考补贴、安保、餐饮、住宿、保险）。
- 教练进修与培训。
- 设备损坏、事故赔偿。

### 7.3 声誉体系
| 声誉类型 | 影响 |
|---|---|
| 学校声誉 | 拨款、招生质量、赞助 |
| 教练声誉 | 外聘邀请、讲座邀请、承办资格评审 |
| 圈内口碑（论坛） | 学生与家长对你的看法，影响招生和事件 |
| 教育局关系 | 承办资格、名额倾斜、政策信息 |
| 学长关系 | 反哺强度 |

### 7.4 预算与账本
- 月度账本：收入、支出、净现金流。
- 预算分配：设备 / 培训 / 福利 / 储备金，系统自动提示风险。
- 贷款（可选）：向学校借款，有利息，逾期会触发"财务预警"。

## 8. 机房建造

### 8.1 可布置物品

| 分类 | 物品 | 效果 |
|---|---|---|
| 电脑 | 低配 / 中配 / 高配 / 服务器级 | 影响编码效率、编译速度、故障率、评测机性能 |
| 显示器 | 单屏 / 双屏 / 护眼屏 | 效率、视力、疲劳 |
| 键鼠 | 普通 / 机械键盘 / 静音键盘 | 手速成长、噪音（机械键盘有"打字声"加成，也会吵到别人） |
| 座椅 | 普通椅 / 人体工学椅 | 疲劳增长速度、腰椎 buff/debuff |
| 环境 | 空调、暖气、绿植、窗帘、灯光、降噪板、空气净化器 | 专注度、体力、心情 |
| 福利 | 饮水机、零食柜、咖啡机、沙发、微波炉 | 回复体力和心情，有副作用（咖啡因依赖、零食影响体重） |
| 教学 | 白板、投影仪、讲台、评测服务器 | 讲课效率、模拟赛体验、承办资格 |
| 网络 | 路由器、交换机、**内网隔离设备**、监控 | 网速、防作弊、承办资格 |
| 电力 | **UPS 不间断电源**、稳压器、备用发电机 | 防停电影响比赛，承办赛事关键 |
| 其他 | 书架、奖杯柜、海报、吉祥物（玄学加成） | 氛围、士气、RP 加成 |

### 8.2 布置系统
- 网格化摆放，可旋转、拆除、搬迁；支持"蓝图复制"。
- 机位数量上限由房间面积决定；可扩建、增设第二机房。
- **布局影响**：
  - 间距太近：交头接耳、抄袭风险上升，噪音增加。
  - 间距太远：交流收益下降，教练巡视效率下降。
  - 窗边光线好，但夏天会晒；靠近空调出风口更舒服，但容易感冒。
  - 通道宽度影响拥挤与应急疏散，承办赛事时检查要求。

### 8.3 设备状态
- 每件设备有耐久度和故障概率。故障类型：蓝屏、断网、键盘失灵、显示器闪屏、风扇异响、电源故障。
- 维护：日常保养（降低故障率）、维修、更换。
- 随机事件：比赛前夜评测机宕机、老电脑 TLE（编译慢）、散热不足死机。
- **设备代际**：硬件会过时，新版评测环境要求更高配置。

### 8.4 评测机系统
- 自建评测机性能影响：模拟赛评测速度、评测环境与正式赛的差异（"机子快 / 机子慢"）。
- 机子太快：学生在模拟赛中卡常成功，正式赛 TLE。
- 机子太慢：模拟赛学生被冤枉 TLE，信心下降。
- 玩家可调整**评测机倍率**，与正式赛评测机对齐，减少"评测机差异"带来的意外。

## 9. 学生系统

### 9.1 年级与生命周期
- **入队**：初一至高一新生可加入。招生期在 9 月，另有随机插班、转学生。
- **退役**：初三至高三进入退役窗口。
  - **初三**：中考压力，约 50% 学生会在中考前选择退役或半退役。
  - **高一**：高中新生，可能加入或继续。
  - **高二**：保送与强基窗口关键期。
  - **高三**：高考与毕业压力最高，在最后一场符合资格的赛事或毕业节点退役；不默认具有当年 NOI 参赛资格。
- 退役原因：
  - 参加完当年重要比赛后自然退役
  - 学业压力、成绩不理想、对 OI 失去热情（AFO）
  - 家长干预、转去其他方向
  - 保送 / 签约 / 达成目标后提前退役
- 学生在队时间最长为初一至高三共 6 年。6 月触发离队规划，实际退役时间以最后一场符合资格的赛事和毕业节点为准；能否参加 7 月赛事由赛季规则包决定，不延长在校年限。

### 9.2 基础属性（0~100）

| 属性 | 说明 |
|---|---|
| 思维 | 想出解法的能力，影响难题 |
| 编码 | 写代码速度与正确性 |
| 细节 | 影响挂分概率 |
| 心理 | 抗压，影响比赛发挥 |
| 学习力 | 学习新知识的吸收效率 |
| 体力 | 当前精力，影响效率 |
| 心情 | 影响学习状态、留队意愿 |
| 学业 | 文化课成绩，过低触发干预 |
| 热爱 | 对 OI 的兴趣，影响自习积极性与留队 |
| **RP（隐藏）** | 玄学人品，影响比赛随机事件，可通过"拜神""幸运物"微调 |

### 9.3 衍生状态
- 疲劳、压力、自信、焦虑、**倦怠**（长期高强度训练累积）、**竞争压力**（排名焦虑）。
- **状态标签**：状态火热 / 低谷期 / 瓶颈期 / 开窍前夜 / 恋爱中（影响专注度的一种事件）。

### 9.4 知识点能力
每个知识点 0~10 级熟练度，同时记录经验值。

| 类别 | 知识点 |
|---|---|
| 基础 | 模拟、枚举、排序、前缀和、差分、二分、贪心、双指针 |
| 搜索与递推 | DFS/BFS、剪枝、递推、记忆化、背包 DP |
| 数据结构 | 栈队列、堆、并查集、ST 表、线段树、树状数组、平衡树、可持久化、分块 |
| 图论 | 最短路、生成树、拓扑、LCA、强连通、网络流、二分图匹配 |
| 数学 | 数论、组合、概率期望、矩阵、FFT/NTT、容斥、莫比乌斯 |
| 字符串 | KMP、Hash、Trie、AC 自动机、后缀数组、SAM |
| 进阶 DP | 树形 DP、状压、数位 DP、斜率优化、四边形不等式、DP 套 DP |
| 其他 | 构造、交互、随机化、计算几何、博弈论 |

- **前置依赖**构成技能树，如线段树需要二分、递归；网络流需要最短路和图论基础。
- **知识点难度标签**：入门、普及、提高、省选、NOI，对应后文的题目颜色。
- **遗忘曲线**：长期不复习的知识点会缓慢衰减，需要练习或讲评巩固。

### 9.5 能力维度（比赛向）

| 维度 | 说明 |
|---|---|
| 算法广度 | 已掌握知识点数量 |
| 算法深度 | 高等级知识点熟练度 |
| 代码实现 | 码量大题的发挥 |
| 调试能力 | 找 Bug 的能力，**对拍**熟练度 |
| 骗分能力 | 暴力、打表、部分分设计，比赛中的"保底" |
| 卡常能力 | 优化常数，对 TLE 题有帮助 |
| 应试策略 | 时间分配，先做哪道题 |

### 9.6 天赋系统
每个学生有 1~3 个天赋，部分隐藏，在特定事件、谈话或比赛中揭示。

**正面天赋**
- 🧠 **灵光一现**：偶尔顿悟，难题得分大幅提高。
- ⚡ **手速怪**：大码量题表现好。
- ❤️ **大心脏**：基本不受紧张影响。
- 📚 **过目不忘**：学习新知识点速度 +30%。
- 🔍 **细节狂魔**：极少挂分。
- 🎯 **数学直觉**：数学类知识点成长更快。
- 🛠️ **调试大师**：找 Bug 速度快，对拍熟练。
- 🏃 **应试达人**：模拟赛和正式赛差距小。
- 🌟 **天选之子**：RP 初始较高。
- 🤝 **团队核心**：带动周围同学成长。

**负面 / 双刃剑天赋**
- 😴 **嗜睡**：容易困，但睡眠恢复快。
- 🎮 **网瘾少年**：网赛收益高，但容易摸鱼。
- 🧨 **粗心大意**：易挂分。
- 😰 **玻璃心**：成绩波动时心情大幅下降。
- 🌙 **夜猫子**：夜间高效，白天低效。
- 🔥 **偏科**：某类知识点极强，其他较弱。
- 🐢 **慢热型**：前期成长慢，后期稳定。
- 🧊 **考场失忆**：模拟赛强，正式赛容易想不起来。
- 🧪 **实验狂**：爱写没必要的优化，容易浪费时间，但偶尔撞出奇招。
- 🪞 **自负**：喜欢走偏门做法，容易 WA 又不愿听劝。

**成长曲线**
- 早熟型：初中强，后期停滞
- 大器晚成型：初期平庸，高中爆发
- 稳定型
- 天才型：极少，需要特殊事件触发
- **爆发型**：长期停滞后在某次事件后突然飞跃

### 9.7 学生背景
- 家庭背景：经济条件、家长对 OI 的态度（支持 / 反对 / 观望）、期望（要保送、要强基、只是兴趣）。
- 入队来源：本校直升、外校转入、机构推荐、学长推荐、特长生。
- 目标倾向：保送、强基、竞赛加分、纯兴趣、混经历。目标会随成绩和政策变化。

### 9.8 性格与关系
- 性格：内向 / 外向 / 竞争心强 / 佛系 / 完美主义 / 社恐 / 话痨。
- 关系：友谊、竞争、师徒、**CP**（影响专注，也有正面互相督促）、对手。
- 互动影响：
  - 友谊：一起学习，互相帮助。
  - 竞争：压力大但成长快，也可能互相拉低心情。
  - 师徒：高年级带低年级，"传帮带"成长加成，同时消耗高年级精力。
  - 小团体：形成集体氛围，影响全队士气。
- 关系可以被教练引导，如调换座位、分配结对。

### 9.9 学生名单界面
- 列表视图：姓名、年级、综合评分、状态、天赋图标、近期趋势箭头。
- 详情页：
  - 雷达图（核心属性）
  - 知识点树（可点击查看学习进度）
  - 历史成绩曲线（模拟赛、网赛、正式赛）
  - 心理状态、家长态度、目标
  - 关系图谱
  - 日志（近期事件、谈话记录）
- 支持筛选和排序：年级、擅长方向、近期状态、天赋、风险等级（可能退役 / 倦怠 / 学业危险）。
- **队伍总览**：年级分布、各知识点平均水平、拥有的名额潜力、潜在退役预测。

## 10. 教练系统

### 10.1 教练属性
| 属性 | 影响 |
|---|---|
| 讲课能力 | 讲课效率 |
| 出题能力 | 自出题的质量，出题事故概率 |
| 管理能力 | 排班、冲突调解、承办赛事统筹 |
| 沟通能力 | 谈话效果、家长关系、校领导关系 |
| 算法储备 | 个人技能树，决定能教的内容上限 |
| 精力 | 每日行动点，影响活动数量 |
| 人脉 | 外校交流、邀请、承办资格 |

### 10.2 教练技能树
- **讲课线**：板书、PPT、实战演示、启发式、一对一辅导。
- **出题线**：命题技巧、造数据、验题、防 AK 设计、避免事故。
- **管理线**：排班、危机处理、统筹、预算控制、**赛事运营**。
- **沟通线**：谈心、家长沟通、公关、校领导、媒体。
- **专业线**：算法进修，各知识点同步学生内容。

### 10.3 教练职称
初级 → 中级 → 高级 → 特级教师，需要积累成绩与年限，可提升每日精力上限、讲课加成和承办资格评分。

### 10.4 教练成长途径
- 进修与培训（消耗时间和资金）
- 参加其他教练的交流会
- 为大型赛事命题或担任监考 / 裁判，积累经验
- 向学长学习（学长回校时有可能的"教学相长"事件）

### 10.5 教练精力
- 每日精力 100，不同活动消耗不同：讲课 20、模拟赛监考 15、出题 30、谈话 10、出差 40 等。
- 精力透支会降低所有活动的效果，并增加事故概率。
- 通过休息、助教分担、设备自动化（如评测机减少人工批改）来缓解。

### 10.6 助教
- 可聘用学长、外聘教师、研究生。
- 助教有专长，如数学方向、图论方向，承担部分讲课、批改、监考。
- 助教有薪资和心情，会流失。

## 11. 教练活动

### 11.1 讲课
- 选择知识点、对象（全队 / 年级 / 个人 / 小组）、形式（板书 / PPT / 实战演示 / 讨论课）。
- 效果受影响因素：教练掌握度、学生前置知识和学习力、状态、设备（投影、白板）、座位布局。
- 难度选择：
  - **过易**：效率 ×0.3，学生觉得无聊。
  - **适中**：最佳（略高于学生当前水平）。
  - **过难**：效率 ×0.2，心情下降，可能打击自信。
- 讲课后可布置**课后题单**，下一次自习自动执行。

**学习增益参考公式**
```
ΔXP = 基础值 × 学习力系数 × 状态系数 × 难度匹配系数 × 设备系数 × 教练系数 × 天赋系数
难度匹配 d = 授课难度 - 学生该点等级
  d < 0       → ×0.3（太简单）
  0 ≤ d ≤ 1.5 → ×1.0~1.3（最佳区间）
  1.5 < d ≤ 2 → 从 ×1.3 线性降至 ×0.2
  d > 2       → ×0.2，且心情 -5~-15
```

### 11.2 模拟赛
- **赛制选择**：
  - CSP 风格（2 小时~3.5 小时，4 题）
  - NOIP 风格（4 题，4.5 小时左右）
  - 省选风格（两天，每天 3 题）
  - NOI 风格（两天，每天 3 题，难度高，含交互 / 提交答案等）
  - IOI 赛制（有反馈、可多次提交）
  - ACM 风格（罚时、气球，可选）
- **题目来源**：
  - 购买题库（有难度和质量评级，可能"撞题"，学生早已做过）
  - 自己出题（消耗时间；出题能力影响质量；风险有"题面有歧义""数据太水""标程挂了"）
  - 往年真题（质量稳定，但学生可能提前接触过）
  - 外校联考（邀请友校，提升竞争感）
  - 学长出题
- **模拟赛配置**：
  - 是否开放文件 IO（freopen）检查
  - 是否使用 O2、栈空间设置
  - 评测机倍率
  - 是否封榜、是否实时榜单
  - 是否严格模拟正式赛环境（如 NOI Linux 风格、无补全）
- **赛中观察**：
  - 按赛制展示信息：有反馈赛可显示正式评测状态；无反馈 OI 赛只显示编译、自测和主观进度，赛后才公开正式 AC、WA、TLE、RE、MLE、CE
  - 头顶气泡：紧张、顿悟、摸鱼、崩溃
  - 有反馈赛按配置显示榜单；无反馈赛不显示真实分数，封榜信息范围见[比赛模拟](04-competition-simulation.md)
  - 教练介入：训练赛可按规则发放零食、给予鼓励；正式赛仅能处理规则允许的后勤和统一通知
  - 突发：机器故障、题目勘误公告（出题事故）
- **赛后**：
  - 自动生成成绩单、各题通过率、各子任务得分
  - 失分原因分类：算法错误 / 细节 / 超时 / 爆 int / 数组越界 / 忘记 freopen / 多测不清空 / 时间分配
  - 讲评：可选择讲评深度，影响知识点和心理成长
  - 排名焦虑：成绩影响学生信心

### 11.3 网赛
- 平台：类 Codeforces / AtCoder / 洛谷月赛 / LOJ。
- **Rating** 系统：学生各自的 rating 随网赛波动，是长期成长指标。
- **颜色分段**：灰 → 绿 → 青 → 蓝 → 紫 → 橙 → 红（可自定义命名）。
- 收益：实战经验、特定知识点提升、Rating 提升、学生热爱度上升。
- 风险：熬夜（影响次日状态）、掉分心态崩、沉迷。
- 教练可强制 / 限制参赛，允许自愿报名。

### 11.4 自习与刷题
- 学生自主刷题，受性格与兴趣影响，可能偏向自己喜欢的方向。
- **题单系统**：教练可指定题单（如"提高组数据结构 30 题"），按颜色难度分级。
- 对拍、造数据、写题解作为自习中的小活动，影响调试能力。

### 11.5 放假与休息
- 全队放假、个别学生放假、周末与节假日安排。
- 活动：看电影、聚餐、爬山、烧烤、桌游、团建、密室逃脱，增加心情、体力、凝聚力。
- 长期不放假累积倦怠，可能引发学生退队、家长投诉。
- **放假也有机会成本**：错过训练时间，但减少考试前的崩溃风险。

### 11.6 个人谈话
- 类型：鼓励、批评、规划、心理疏导、家长沟通、学业提醒。
- 对玻璃心、网瘾少年、自负型、倦怠学生有专门选项。
- 有冷却时间和精力消耗，选错话术会适得其反。

### 11.7 外出活动
- 外校交流、夏令营、冬令营、名校宣讲、参观大学、拜访企业、参加学术会议。
- 带来资源、声誉、人脉和稀有事件（如遇到大佬、拿到内部资料）。

### 11.8 集训
- **校内集训**：寒暑假集中安排，高强度，疲劳增长快。
- **外聘集训**：花钱请机构或名师，成长快，但可能导致学生被"挖角"。
- **省队集训**：入选省队的学生被集中培训，队伍内暂时缺席，名额紧张时需要权衡。

## 12. OI 赛事与规则体系

### 12.1 赛事阶梯

| 阶段 | 赛事 | 说明 |
|---|---|---|
| 入门 | 校内选拔、区级比赛、联赛 | 初一、初二主要目标 |
| 初级 | CSP-J | 初中与高一新手的重要目标 |
| 进阶 | CSP-S、NOIP | 决定省选资格，也是保送、强基的基础 |
| 高级 | 省选（联考） | 决定省队资格 |
| 顶级 | NOI | 决定金银铜牌、保送、签约、国家集训队 |
| 额外 | 冬令营、APIO、集训队互测、CTSC、国家队选拔、IOI | 后期内容 |
| 邀请赛 | 友校联赛、省内强校联盟赛 | 可选，提高关系与声誉 |

### 12.2 赛制与规则细节（OI 味）

| 机制 | 说明 | 游戏表现 |
|---|---|---|
| **OI 赛制** | 赛时不公布评测结果（或仅样例），赛后统一评测 | 学生不知道自己真实得分，容易自我感觉良好或崩溃 |
| **子任务 / 捆绑测试** | 每题分成多个子任务，如 n≤20 的暴力、特殊性质、满分做法 | 每道题显示部分分阶梯，学生会选择"拿多少分" |
| **文件输入输出** | 必须使用指定文件名读写 | "忘记 freopen""文件名写错"挂分事件 |
| **编译选项** | 如 O2、语言标准、栈空间 | 卡常题受编译选项影响 |
| **时间 / 空间限制** | 不同题目不同限制 | TLE / MLE，评测机速度差异引发"玄学" |
| **禁用项** | 禁止特定头文件 / 系统调用 / 网络 | 违规则该题 0 分，学生可能因"习惯"违规 |
| **考场环境** | 无补全、无网络、有限的编辑器，或 Linux 环境 | 不适应则打字慢、命令不熟 |
| **题型** | 传统题、交互题、提交答案题、通信题 | 各有不同能力需求 |
| **题目特色** | 签到题、毒瘤题、防 AK 题、构造题、卡常题 | 能力维度不同，题目配色分级 |

### 12.3 题目难度配色
参考社区常见的颜色分级（可自定义命名）：

| 颜色 | 难度 | 对应 |
|---|---|---|
| 红 | 入门 | 校内 / CSP-J T1 |
| 橙 | 普及− | CSP-J T2~T3 |
| 黄 | 普及/提高− | CSP-J T4 / CSP-S T1 |
| 绿 | 普及+/提高 | CSP-S T2、NOIP T1~T2 |
| 蓝 | 提高+/省选− | NOIP T3~T4 |
| 紫 | 省选 / NOI− | 省选 |
| 黑 | NOI / 国家集训队 | NOI 压轴 |

### 12.4 比赛结算模型

```
学生期望得分(题 i) = Σ 子任务通过概率 × 子任务分值
相关知识 K = Σ(知识点等级 × 10 × 权重)，权重之和 = 1
解题能力 A = 0.6K + 0.25思维 + 0.15应试策略
解题概率 P = sigmoid((A - 子任务需求 D + 有界状态修正) / σ)
  A、D 都采用 0~100 尺度；σ 默认 12

挂分概率 = clamp(基础挂分率 × (1 - 细节/150) × 疲劳系数 × 压力系数 × 天赋系数, 0, 0.6)
每个提交版本只生成一次实际错误，子任务按测试点和依赖评测。
时间分配、真实得分和赛中可见信息分别计算，详细规则见下文链接。
```

完整的时间预算、示例算分、随机采样与复核规则见[比赛与评测模拟](04-competition-simulation.md)。

### 12.5 部分分与骗分
- 每道题有若干子任务档，玩家可以在模拟赛前向学生强调"拿满部分分"。
- 学生会有"骗分意识"：打表、暴力、随机化、猜结论。成功率取决于骗分能力和题目设计。
- 防 AK 题和强数据让骗分失败，数据水则骗分成功（被圈内吐槽的情景）。

### 12.6 奖项、分数线与划线
- **获奖等级**：一等奖、二等奖、三等奖（CSP / NOIP）；金、银、铜牌（NOI）。
- **划线**：比赛成绩公布后触发"划线事件"。
  - 省内按**排名比例**划线，如前 X% 为省一。
  - 按规则包选择全国或省内划线，并显式配置参赛资格、最低分和同分处理；这里不复刻任何现实年度的官方划线办法。
  - **擦线剧情**：差 1~5 分的学生会出现特别事件，如申诉、复查、遗憾。
- **成绩申诉**：赛后可以申请复核，成功率与证据有关；可能发现评测错误，也可能发现自己挂分。
- **资格线**：不同省份的省选资格线、省队线、NOI 线不同，名额约束下形成竞争。

### 12.7 比赛事故与争议
- 题目有歧义、数据有错、标程有 bug。
- 评测机宕机、评测超时、数据泄露。
- 选手发现题面错误，要求更正，影响所有人。
- 作弊、抄袭、串通，触发**查重与禁赛**机制。
- 玩家可作为命题人、监考、裁判，亲身参与事故处理。

### 12.8 OI 特色机制清单（用于事件、彩蛋、数值）
- **RP 玄学**：考前不洗头、穿幸运 T 恤、拜神（贴神仙头像）、"RP++"，有微弱真实加成，也有负面彩蛋（RP 清零）。
- **AFO / 退役梗**：学生说"我退役了"可能是玩笑，也可能是真的。
- **"我是 flag"**：学生立下 flag（"这次一定 AK"），触发反向或正向结果。
- **考前仪式**：清空数组、检查 freopen、对拍到半夜；教练可以安排"考前检查清单"。
- **机构与圈子**：培训机构、论坛、社群、直播讲课对学生的吸引力。
- **大佬与神仙**：偶遇集训队选手、前国家队选手，触发特殊事件，学生"膜拜"。
- **梗化装备**：机械键盘、Dev-C++ 字体、Codeforces 紫色头像（取得成就解锁）。

## 13. 承办比赛与奖励名额系统

承办赛事是长期玩法的核心内容之一。承办不仅是荣誉，更是资金、名额、声誉与关系的博弈。

### 13.1 承办类型

| 类型 | 级别 | 需要的学校等级 | 说明 |
|---|---|---|---|
| 校内赛 / 友谊赛 | 校级 | Lv.1+ | 自己办，成本低，用于选拔与练兵 |
| 区 / 市联赛 | 地区级 | Lv.2+ | 提升声誉，吸引生源 |
| **认证考点**（CSP 第二轮等） | 省内 | Lv.3+ | 提供机房作为考点，有硬件和管理要求 |
| 省内邀请赛 / 联盟赛 | 省级 | Lv.4+ | 联合多校，提升关系 |
| **省选考点 / 联考** | 省级 | Lv.5+ | 难度与关注度高，名额与声誉回报大 |
| **冬 / 夏令营承办** | 全国 / 省级 | Lv.6+ | 邀请全国强队，需要住宿、餐饮、报告厅 |
| **NOI 承办** | 全国 | Lv.7+，需多年申请 | 终极荣誉，周期为数年一次轮换 |
| 友校联赛（自办系列赛） | 自定义 | Lv.4+ | 自办品牌赛事，可持续经营 |

### 13.2 承办流程

```
① 申请 → ② 资质评估 → ③ 获批 → ④ 筹备期 → ⑤ 比赛日 → ⑥ 赛后 → ⑦ 评估与奖励
```

**① 申请**
- 在"承办中心"提交申请，需要消耗人脉点和一部分申请经费。
- 申请评分由以下因素决定：学校等级、教练声誉、教育局关系、设备条件、历史承办记录、竞争学校的申请情况。
- 有些赛事采用**轮换制**，多年才有一次机会，需提前几年布局。

**② 资质评估**
评估项目（示例，可配置）：

| 项目 | 内容 |
|---|---|
| 机位数量 | 满足参赛人数，另加备用机 ≥ 10% |
| 评测环境 | 评测服务器、评测环境与官方对齐 |
| 网络 | 内网隔离、防外网访问、稳定性 |
| 电力 | UPS / 备用电源，防停电 |
| 监控 | 摄像头、监考位 |
| 场地 | 候考区、休息区、洗手间、通道 |
| 人员 | 监考老师、技术人员、志愿者 |
| 食宿（大型赛事） | 住宿、餐饮、交通 |
| 应急预案 | 停电、故障、突发状况 |

评估结果分为：不合格 / 合格 / 优秀；优秀可获得额外加分，影响后续奖励。

**③ 获批**
获批后进入筹备期，学校给予基础补贴（可能不足以覆盖，需要自筹）。

**④ 筹备期**
- 机房改造：新增机位、网络改造、UPS、监控。
- 培训：监考员、技术人员、志愿者（可由本校学生担任，部分学长也可回校协助）。
- 压测：评测机压力测试，模拟高并发，发现隐患。
- 物资：矿泉水、零食、横幅、证件、指示牌。
- 公关：宣传、邀请嘉宾，赞助洽谈。
- 筹备进度条：由多项子任务组成，玩家分配精力与预算。
- 若筹备不足，比赛日出事故概率上升。

**⑤ 比赛日**
- 实时运营界面：
  - 监控各机房状态：在线人数、评测队列、网络状态、电力状态
  - 突发事件处理：
    - 停电 / UPS 切换
    - 评测机宕机 / 评测队列拥堵
    - 选手机器故障，需要换机
    - 选手突发疾病
    - 选手举报抄袭 / 作弊
    - 题目勘误 / 争议
    - 家长闹事、媒体采访
  - 每个事件都有多种处理方式，影响比赛公平和声誉。
- 自己学校的学生**不能享受不当照顾**，若被发现有偏袒，会触发丑闻。

**⑥ 赛后**
- 成绩公布、申诉处理、颁奖典礼（可布置会场）。
- 总结报告：收到的反馈、事故记录、资金盈亏。

**⑦ 评估与奖励**
- 根据比赛运营评分（流畅度、事故数量、公平性、参赛者满意度）得到**承办评级**：S / A / B / C / D。

### 13.3 承办奖励

| 奖励类别 | 内容 |
|---|---|
| **额外名额** | 见 13.4 |
| 经费补贴 | 上级拨付补贴、赞助收入、报名收入 |
| 设备赞助 | 评测服务器、网络设备、桌椅等 |
| 声誉 | 学校声誉、教练声誉、圈内口碑提升 |
| 教育局关系 | 增加，利于后续承办资格与政策倾斜 |
| 承办资质等级 | 累积"承办等级"，解锁更高级别赛事承办资格 |
| 命题组交流 | 获得公开题库、通用命题经验和赛后培训机会；未公开赛题不得提前进入本校训练 |
| 教练评优 | 优秀教练、承办单位荣誉称号 |
| 学长回校 | 承办高光事件吸引学长回校协助，并增加其反哺意愿 |
| 生源吸引 | 招生期的生源质量和数量上升 |

### 13.4 奖励名额详细设计

承办奖励是游戏规则包中的特色玩法，不代表现实承办方天然拥有加分、升学或额外参赛权。名额视为有类型、期限和使用条件的**资源**；交换、跨届保留等操作必须由对应规则显式允许。详见[经营与名额规则](05-economy-and-hosting.md)。

**名额类型**

| 名额 | 说明 | 来源 |
|---|---|---|
| 承办方参赛名额 | 承办赛事时，本校可额外增加参赛名额（如 CSP 增加席位、省选增加本校参赛席位） | 承办 CSP 考点、省选考点 |
| 省队名额倾斜 | 省队选拔时，承办单位的学生获得若干"优先考察"席位或额外加分 | 承办省选、省内邀请赛 |
| 夏 / 冬令营名额 | 承办令营时，本校获得额外营员席位 | 承办冬 / 夏令营 |
| NOI 东道主名额 | 承办 NOI 时，本校或本省获得额外参赛席位 | 承办 NOI（极稀有） |
| 保送 / 强基推荐名额 | 学校层面分配的推荐资格（受上级政策影响），承办评级高时增加 | 承办评级 A 以上 |
| 友校联盟席位 | 自办联盟赛时，各校互换参赛席位 | 联盟赛事 |

> 具体名额数量由配置表决定，随承办评级、赛事规模、政策松紧动态变化。

**名额分配界面**
- 面板显示：名额池、名额类型、使用期限、候选学生、候选学生的指标（成绩、潜力、状态、家长关系、目标）。
- 玩家可以：
  - 直接指定
  - 举办**内部选拔赛**，按成绩分配
  - 在符合条件的候选人中按事先公布的程序抽签
  - 仅当名额允许跨届且尚未到期时保留，否则到期失效
  - 仅当名额允许转让时与友校交换，记录审批与交易来源

**名额分配的影响**

| 分配方式 | 效果 |
|---|---|
| 公平选拔（按成绩） | 士气↑，公平度↑，可能错失潜力股 |
| 倾斜培养（给潜力股） | 潜力股成长↑，但其他学生心情↓，家长可能不满 |
| 关系户 / 领导打招呼 | 短期获得校长 / 教育局关系↑，学生士气↓，被曝光时丑闻 |
| 家长游说 | 家长关系相关事件，可能资金赞助，但声誉风险 |
| 名额浪费（不用） | 下一年承办资格的评分下降 |

**名额相关事件**
- 校长要求给某学生一个名额（抉择：同意 / 拒绝 / 折中）。
- 家长要求"让孩子也去一下，哪怕陪跑"。
- 学生 A 与 B 为同一个名额竞争，赛后情绪冲突。
- 名额被上级收回或调整（政策变化）。
- 友校想用名额换你的出题资源。
- 举报：有人举报你名额分配不公，触发调查。

### 13.5 承办风险与惩罚
- 重大事故：评测大面积故障、题目泄露、停电导致比赛中断，将导致评级下降、声誉下降。
- **违规处罚**：偏袒本校学生、泄题、成绩造假，触发：
  - 罚款
  - 取消承办资格 N 年
  - 学校声誉大幅下降，学生名额被取消
  - 教练被"约谈"、扣职称积分
- 承办失败会留下"黑历史"，在后续申请中长期有负面加权，但可通过多年良好运营逐渐消除。

### 13.6 承办成长路线（示例）
```
校内赛 → 区联赛 → CSP 考点（Lv.3）→ 省内邀请赛 →
省选考点（Lv.5）→ 夏令营（Lv.6）→ NOI 承办（Lv.7+，多年一次）
```
每个阶段需要的设备、人力、声誉逐级提升，形成清晰的长期目标。

### 13.7 自办赛事品牌
- 玩家可创办自己的**品牌赛事**（如"XX 杯邀请赛"）。
- 品牌指数（参赛校数量、题目质量、事故率）长期积累。
- 高品牌指数可吸引赞助、媒体报道、名校参赛，成为自循环的收益来源。

## 14. 升学与出路

### 14.1 出路类型

| 出路 | 条件（示例，可配置） | 说明 |
|---|---|---|
| 保送 | NOI 金牌 / 国家集训队 / 国家队 | 顶级出路，学生退役 |
| 强基 / 综合评价 | 获奖 + 高考成绩 | 需要文化课，学业不能太差 |
| 竞赛加分 / 降分 | NOI 银牌、省一等奖等 | 与政策相关，可能收紧 |
| 签约 / 提前批 | 名校签约 | 与学校、家长、学生意愿相关 |
| 普通高考 | 无奖或奖项不足 | 需要回归学业 |
| 出国 / 国际学校 | 特定背景 | 少量学生走这条路 |
| 转其他方向 | 转数学、物理、其他 | AFO 后的选择 |

### 14.2 政策随机事件（长期）
- 竞赛加分政策收紧 / 放宽：影响家长态度与学生目标。
- 强基招生比例变化：影响 OI 热度。
- 保送政策收紧：影响 NOI 的价值感。
- 新高考改革：影响文化课时间分配。
- 这些事件会通过新闻、校长通知、家长群消息传递。

### 14.3 退役后
- 学长档案：去向、成绩、联系状态。
- 触发事件：回校讲课、捐赠、邀请你参加学术活动、推荐学弟学妹。
- 学长关系值维护：定期联系、邀请参加校庆，可提升反哺强度。
- 学长可成为助教、外聘教练、赞助商代表、命题组成员。

## 16. 随机事件与事件链

### 16.1 事件类型
- **正面**：大佬来访、企业赞助、学生灵感爆发、校长视察给予奖励、学长回校讲课、学生互助、免费题库。
- **负面**：停电、断网、家长要求退队、学生沉迷游戏、学生生病、设备损坏、论坛爆料、机构挖人。
- **抉择事件**：
  - 学生想参加与比赛冲突的活动，同意还是拒绝？
  - 学校要你多招人，但机位不足。
  - 某学生天赋极高但学业严重不及格，是否向学校求情？
  - 名额分配争议。
  - 作弊 / 抄袭处理。
  - 学生想退役，挽留还是尊重？
- **OI 特色事件**：
  - 学生考前不洗头，被同学吐槽。
  - 学生立 flag，结果如何。
  - 题目出现勘误，大家发现自己白做了半小时。
  - 数据太水，暴力过了；数据太毒，所有人崩溃。
  - 模拟赛 AK 后膨胀。
  - 学生发现"一个惊天 Bug"，评测机全部 AC。

### 16.2 事件链
- 每个事件可以触发后续事件，形成长线剧情。示例：
```
[学生 A 连续两次 CSP 差一点获奖]
   → 谈话：鼓励 / 批评 / 放任
      → 鼓励：A 状态上升，进入"逆袭线"，NOIP 触发高光事件
      → 批评：A 玻璃心，进入"倦怠线"，可能退役
      → 放任：A 自行调整，随机结果
```

### 16.3 事件数据格式（示例）
```json
{
  "id": "evt_quota_principal_request",
  "trigger": { "season_phase": "after_hosting", "min_quota": 1, "principal_relation": ">30" },
  "text": "校长打电话：李主任的孩子也想去试试，你看……",
  "choices": [
    { "text": "同意", "effects": { "principal_relation": 15, "fairness": -10, "morale": -8, "scandal_risk": 0.2 } },
    { "text": "婉拒，建议走选拔赛", "effects": { "principal_relation": -5, "fairness": 5 } },
    { "text": "折中：增设一个观察席位", "effects": { "budget": -2000, "principal_relation": 5, "fairness": 0 } }
  ]
}
```

## 17. 成就与荣誉（取代结局）

成就不会终结游戏，只提供长期目标和展示。

| 类别 | 示例 |
|---|---|

## 19. 技术实现建议

本章为候选方向，尚未确定技术栈。模块边界、可验证的数据契约与存档要求见[技术设计](08-technical-design.md)。

### 19.1 引擎与技术栈
- **引擎**：Godot 4 / Unity（体素插件）/ Three.js（网页版）。
- **数据驱动**：学生、知识点、事件、物品、赛事、政策、承办规则使用 JSON / CSV 配置，便于扩展与平衡。
- **事件脚本**：简易 DSL 或 JSON 触发器 / 效果表达式，支持 mod。

### 19.2 模拟核心
- 校队经营以“时段”为基本逻辑单位；比赛内部可使用虚拟分钟子步骤，统一由日程分配时间预算，倍速只改变推进速度。
- 学生行为使用状态机（学习 / 刷题 / 休息 / 摸鱼 / 聊天 / 吃饭 / 睡觉 / 打网赛 / 比赛）。
- 3D 动画仅用于表现，逻辑与表现分离。
- 随机数使用可复现种子，方便调试和"种子分享"。

### 19.4 存档
- 每游戏日自动存档，多存档位。
- 存档包含：世界种子、学校、学生、事件状态、竞争学校、历史记录。
- 支持"年度快照"，方便回顾校史。

### 19.5 性能
- 学生上限约 30~50，非常轻量。
- 机房设备使用实例化渲染；承办大型赛事时参赛选手以 NPC 形式批量渲染，使用简化模型与 LOD。
- AI 学校只做数值层模拟，不实际渲染。

## 22. 后续扩展设想

- **多校联赛模式**：与其他 AI 或玩家学校共同参与联赛、排行榜。
- **自定义学生**：导入真实 ID 与梗，生成专属学生。
- **Steam 创意工坊**：自定义题库、事件、机房皮肤、政策包、承办规则。
- **联机模式**：多名玩家作为不同学校教练同场竞技，或合作承办大型赛事。
- **赛事回放系统**：回看比赛实时榜单与学生屏幕，生成"高光时刻"分享。
- **地区扩展**：不同省份有不同名额、政策和竞争生态。
- **更多学段**：小学启蒙班、大学 ACM 队（学长去向的延伸玩法）。

## 23. 扩展玩法与内容制作入口

本轮设计继续向原有22章之外展开，以下均为可分期采用的扩展草案。完整规则和内容放在独立文档，不要求固定机房原型同时实现。

### 23.1 更深的培养与教练工作

[课程与教研](10-curriculum-and-research.md)将知识拆成36个有前置的节点，提供四条培养路线、12周计划、命题验题和反例实验。学生既可以为赛事补短板，也能围绕一个公开问题做有限期探索，产物可能是证明、反例或失败方法清单。

[教师团队与制度](11-team-staff-and-institutions.md)增加招聘试岗、合同容量、教学排班、文化课协调与年度协议。教练能组建团队，但每位成员仍受精力、时段和岗位限制；有钱不代表可以同时无限开课。

[天赋与个人成长](23-talents-and-personal-growth.md)提供36个天赋候选、八种成长曲线和证据驱动的能力周结算。天赋作用在具体环节，永久成长来自有效练习，不靠重复提交、反复讲评或读档重新抽取。

### 23.2 人物关系与能兑现的故事

[人物故事](12-relationships-and-student-stories.md)增加公开期待、实现瓶颈、初三去向、同分争席、志愿工作、研究项目、导师交接与营费顾虑八条线路。它们引用真实事件和日程，不预先给出必定逆袭或必定退役的结局。

[事件库](16-event-library.md)提供30张完整事件卡与5条多阶段链，每张都有先兆、选项代价、延期核验、冷却、互斥与回退。同一诉求的故事与事件共用实例，避免一位学生被重复要求作出相同决定。

### 23.3 机房以外的经营

[校园与后勤](13-campus-construction-and-logistics.md)把施工、电力、网络、备机、库存、餐饮、住宿和行程纳入排班，包含一套15日扩建方案。采购主机、形成完整机位和通过正式考场验收是不同节点。

[地区生态](14-regions-and-season-ecology.md)提供六类虚构地区、不同风格的对手、年度环境、联盟和联赛；[赞助与学校品牌](15-sponsors-outreach-and-school-brand.md)提供九类合作范本，明确备课、工时、分期收款、限定基金与取消责任。

### 23.4 不同开局与表达方式

[特色开局](17-scenarios-and-difficulty.md)允许从资源有限小校、接班、整改、代际断档、远距出行、环境升级或成熟学校起步，各自有不同的首月与三年问题。难度参数公开，自愿挑战可结束后继续经营。

[成就与表达](18-achievements-and-player-expression.md)包含48项可核验成就、年鉴、照片、校服、纪念物与校史快照。纯装饰不加训练数值，普通成长与体面告别也可以被记录。

### 23.5 可复算的内容与长期减负

[数值与跨年案例](19-balance-and-multiyear-simulation.md)提供一周训练对照、比赛概率和三年现金表；[原创题目与联赛](20-contest-content-and-tournament-design.md)提供12张算法题制作卡、三份试卷与多种赛事包。题目卡尚需标程、数据和验收，不是已可运行题库。

[视听制作](21-art-audio-and-localization.md)给出角色、场景、声音、季节和本地化规格；[长期计划与教练风格](22-automation-and-coaching-playstyles.md)则让玩家在授权范围内委派重复排课。表现、模板和托管都不能额外发放时间、成长或隐藏信息。
